# 2026-11-07 근태 테스트의 휴게 상태 전환 대기

[PR #78의 CI](https://github.com/OpenStudyService/OpenStudy-Frontend/actions/runs/42201181767/job/127836568363?pr=78)에서 근태 테스트가 ‘휴게 시작’ 클릭 직후 ‘퇴근하기’ 버튼의 부재를 검사했다. 이때 API 처리와 현재 근태 재조회가 끝나기 전이라 이전 상태의 버튼이 비활성화된 채 남아 있었다.

`Attendance.test.tsx`에서 기존 `enabled` 헬퍼로 ‘휴게 종료’ 버튼이 활성화될 때까지 기다린 뒤 ‘퇴근하기’ 버튼의 부재를 검사한다. 고정 시간 대기 대신 화면에 반영된 상태를 기준으로 삼는다. 이후 휴게 종료와 퇴근을 실행하고 기존 CSRF·버전·멱등 키 검증을 이어 간다.
