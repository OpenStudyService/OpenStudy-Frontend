# 2026-11-16 AI 채팅: 최근 질문 탭 제거, 대화 기록 전체 삭제

## 1. 배경 / 문제

- 사용자 요청(2026-11-16)
  - 채팅 화면의 기록 영역에서 "최근 질문" 탭을 없앤다.
  - 대화 기록을 지울 수 있는 버튼과 기능을 추가한다.
- 대화별 삭제는 이미 있었다(각 항목 아래 작은 "삭제" 글자). 그래서 사용자에게 형태를 확인했고, "전체 삭제 추가"로 결정했다. 대화별 삭제는 더 잘 보이는 버튼으로 바꾼다.
- 확인 중 사용자가 발견한 문제: 데스크톱 폭에서 대화별 제목 변경·삭제 버튼이 보이지 않았다(5180 live 서버).

## 2. 검토한 선택지

- **전체 삭제 구현**
  - Backend에 "내 대화 전체 삭제" API를 새로 만드는 방법은 API 계약과 Backend 변경이 필요하다.
  - 대화 목록 API는 내 대화를 페이지 없이 모두 돌려준다. 그래서 기존 대화별 삭제 API를 목록 전체에 차례로 호출하는 방법을 택했다. Backend와 계약을 바꾸지 않고, 대화마다 소유 확인이 그대로 적용된다.

## 3. 결정 및 이유

- **전체 삭제 동작**
  - 확인 창("대화 기록 N개를 모두 삭제할까요? 삭제한 대화는 되돌릴 수 없어요.")을 거친다.
  - 대화마다 삭제 API를 차례로 부른다.
  - 이미 없는 대화(404)는 지워진 것으로 본다.
  - 권한이 없어지면(401·403) 나머지를 멈추고 화면을 비운다(기존 규칙).
  - 일부가 실패하면 "대화 N개 중 M개를 지우지 못했어요"라고 알린다.
  - 열려 있던 대화가 지워지면 새 대화 화면으로 돌아간다.
- **"전체 삭제" 위치**: 처음에는 기록 영역 머리에 두었다. 그런데 256px 폭에서 "대화 기록" 제목이 한 글자씩 꺾여서, 목록 바로 위의 작은 줄("대화 N개 · 전체 삭제")로 옮겼다.
- **데스크톱에서 버튼이 안 보이던 원인**
  - 목록(`ul`)이 CSS grid였다. grid 항목의 최소 폭은 기본값이 내용 폭이라, 띄어쓰기 없는 긴 제목이면 항목이 기록 영역보다 넓어졌다(데모 재현: 517px > 256px).
  - 그러면 오른쪽 끝의 버튼이 영역 밖으로 밀려 잘렸다.
  - 모바일에서는 기록 영역이 화면 전체 폭이라 잘 드러나지 않았다.
  - 기존 화면(글자 버튼)에도 있던 문제다.
  - 수정: 열을 `minmax(0, 1fr)`로 고정하고 항목에 `min-w-0`을 줘서 긴 제목을 말줄임으로 자른다.

## 4. 구현 내용

- `Ai.tsx`
  - 최근 질문 탭을 지웠다. 함께 지운 것: 최근 질문 조회, 최근 질문 결과 다시 조회(`runRecent`), 관련 표시 상태, 모바일 버튼 문구 "대화 기록 · 최근 질문"
  - `removeAll`을 추가했다.
  - `History`: 제목 "대화 기록"과 "새 대화"를 두고, 목록 위에 "대화 N개 · 전체 삭제" 줄을 두었다. 대화별 제목 변경·삭제는 연필·휴지통 아이콘 버튼으로 바꿨다(접근성 이름은 기존과 같음).
  - 목록 폭 고정(위 3절)
- `Icon.tsx`: `trash`, `edit` 아이콘을 추가했다.
- 최근 질문 API(`aiReuse.recent`)와 Backend는 그대로 둔다. 계약 시험이 API를 계속 쓴다.

## 5. 검증 결과

- `npm run typecheck`, `npm run lint`, `npm run build` 통과. `npm test` 95개 파일, 858개 통과.
- **추가·변경한 시험**
  - 계약 시험(MSW): 대화 2개를 만든 뒤 전체 삭제 → 확인 문구, 대화별 DELETE 2건, 빈 목록, 열린 대화가 지워져 새 대화로 돌아감.
  - 단위 시험: 3개 중 1개 실패·1개 404 → "대화 3개 중 1개를 지우지 못했어요", 호출 순서. 확인을 취소하면 아무것도 지우지 않음. 최근 질문 탭이 없음.
- **브라우저 확인(데모 모드)**
  - 최근 질문 탭이 없다.
  - 전체 삭제를 확인하면 목록이 비고 새 대화 화면으로 돌아간다.
  - 띄어쓰기 없는 긴 제목에서 수정 전에는 버튼이 영역 밖으로 밀렸고, 수정 후에는 영역 안에 보이며 제목이 말줄임된다(1024px).
  - 700·1280·1920px에서도 버튼이 보인다.
- **실행하지 않은 검증**
  - 실제 Backend(live)에서 전체 삭제: 사용자가 5180 서버에서 확인 중이다.
  - 긴 제목 폭 문제는 jsdom에 레이아웃이 없어 자동 시험으로 잡지 못한다. 브라우저 확인만 했다.

## 6. 남은 작업 / 보류 사항

- 대화가 아주 많으면 전체 삭제가 대화 수만큼 요청을 보낸다. 필요하면 Backend에 일괄 삭제 API를 추가한다.
