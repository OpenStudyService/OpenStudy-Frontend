# 지점 운영시간 입력을 표 형태로 정리

## 1. 배경 / 문제

시·분 입력 적용 후 각 입력에 요일과 시작·종료 라벨이 반복되어 복잡해 보였다. 사용자는 요일별 표 구성과 휴무 체크박스의 오른쪽 배치를 요청했다. [시간 입력 적용 기록](2026-11-18-branch-time-input.md)의 후속 변경이다.

## 2. 검토한 선택지

입력별 라벨을 짧게 줄이는 배치를 먼저 적용한 뒤, 사용자의 추가 요청에 따라 시작·종료를 열 헤더로 한 번만 표시하는 표로 변경했다.

## 3. 결정 및 이유

요일·시작·종료·휴무의 네 열로 정렬한다. 열의 의미를 상단에서 한 번 안내하고 각 행에는 요일과 입력값만 표시해 반복을 줄인다. 스크린리더용 입력 이름은 요일을 포함해 구분할 수 있게 유지한다.

## 4. 구현 내용

- 실제 table과 열·행 헤더를 사용하고 휴무 체크박스를 마지막 열에 배치했다.
- 시작과 종료 시간 입력을 위쪽에 맞추고, 종료 기준일은 종료 시간 아래에 배치했다.
- 휴무인 행은 시간 입력 두 칸 대신 운영하지 않는다는 안내를 표시한다.
- 공통 시간 입력에 시각적 라벨을 숨기는 옵션을 추가했다.

## 5. 검증 결과

- 관련 Vitest 26개 통과. 시간 변환·등록·수정·휴무·종료일 검증을 재확인했다.
- 최종 변경의 `npm run typecheck`, `npm run lint`, `git diff --check` 통과.
- `graphify update .`로 코드 그래프를 갱신했다. SQL 파서 부재 경고는 이전 실행과 동일하며 SQL 변경은 없다.

## 6. 남은 작업 / 보류 사항

실제 브라우저 레이아웃 검증은 미실행이다. 이번 배치 변경 후 전체 테스트와 빌드는 반복하지 않았으며, 이전 시간 입력 작업에서 통과한 결과와 구분한다.

## 후속 변경: 종료 날짜와 시간을 한 줄로 결합

사용자가 종료 열의 두 줄 구성이 복잡하다고 지적했다. 날짜 선택과 시간 입력의 동작은 유지하면서 하나의 테두리 안에 가로로 연결했다. 날짜 선택은 왼쪽의 작은 영역에, 시간은 오른쪽에 배치하고 포커스 표시는 그룹 전체에 적용한다.

시작 열은 시간 입력에 필요한 너비로 고정하고 종료 열에 나머지 공간을 배분했다. 좁은 화면에서는 표 안에서 가로로 스크롤해 한 줄 배치와 입력 공간을 유지한다. 휴무는 마지막 열에 유지한다.

- 관련 Vitest 26개 통과.
- 후속 변경의 타입 검사·린트·diff 검사 통과, 코드 그래프 갱신 완료.
- 실제 브라우저 확인과 전체 테스트·빌드 재실행은 하지 않았다.
