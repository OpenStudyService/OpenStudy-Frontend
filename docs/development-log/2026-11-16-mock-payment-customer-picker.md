# 2026-11-16 · Mock 결제 고객 검색 모달

## 배경 / 문제

결제 목록은 검색 모달에서 고객을 찾을 수 있었고, Mock 결제 입력에서는 검색과 페이징이 있는 별도 선택 목록을 사용했다. 결제 입력에서도 이름·회원번호·연락처를 비교해 고객을 선택할 수 있도록 검색 방식을 맞췄다.

## 결정 및 구현

- 결제 목록과 Mock 결제 입력에서 같은 고객 검색 컴포넌트를 사용한다. 검색창의 키워드를 모달로 넘기고, 고객 결과 표 아래에 공용 페이지 이동을 표시한다.
- 모달이 결제 사이드바 위에 열린다. 선택하면 고객 이름과 회원번호를 표시하고 사이드바에서 이어서 결제를 요청할 수 있다. Escape로 닫으면 검색을 열었던 입력에 초점이 돌아온다.
- 결제할 고객이 필요한 입력에는 선택 안내와 해제 버튼을 제공한다. 고객 선택에는 검색 결과의 이름과 회원번호를 사용한다.

## 검증 결과

- 결제 관련 Vitest 2개 파일, 43개 테스트 통과. Enter 검색, 취소 시 기존 상품 유지, 선택 고객의 결제 요청 반영, 네트워크 오류 뒤 입력과 재시도 키 유지를 확인했다.
- 타입 검사, 린트, `git diff --check` 통과.
- 전용 Mock 서버의 Chrome Playwright 4개 통과. 고객 검색 후 승인·실패 요청, 환불, 모바일 결제 흐름을 확인했다.

## 남은 검증

- 전체 테스트, 배포 빌드 검증, 실제 API 연동 테스트는 실행하지 않았다.
