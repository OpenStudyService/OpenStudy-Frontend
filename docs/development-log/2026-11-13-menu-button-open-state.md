# 사이드바가 열렸을 때 상단 메뉴 버튼 표시

사이드바의 열린 상태를 버튼만 보고도 알 수 있도록 테마의 기본 버튼 강조색과 닫기 아이콘을 적용했다. 버튼의 색상, 아이콘, `aria-expanded`는 기존 메뉴 열림 상태를 함께 사용한다. 사이드바를 접으면 세 가지 표시가 기본 상태로 돌아간다.

데모 빌드로 Chrome에서 1100px·1099px·390px 메뉴 동작을 확인했다. 데스크톱에서 버튼의 배경색과 아이콘이 바뀌고 복원되는지 검증했다. TypeScript, ESLint, 전체 Vitest 814개, 운영·데모 빌드와 산출물 검사가 통과했다. 프론트엔드 Graphify를 갱신했다.
