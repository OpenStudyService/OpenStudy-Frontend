# 2026-11-10 라이브 로그인 화면의 API 연결 문구 제거

## 배경과 결정

`npm run dev:live`로 실행한 로그인 화면에서 내부 연결 모드를 알리는 `실제 API 연결` 문구를 제거해 달라는 요청이 있었다. 로그인 화면의 안내를 데모 모드에서만 렌더링해 기존 `데모 데이터` 표시는 유지했다. 로그인 후 앱 상단의 모드 표시도 유지했다. 기존 표시 정책은 [live·Mock 빌드 분리 기록](2026-11-02-live-mock-build-isolation.md)에 남아 있다.

## 검증 결과

- 타입 검사와 라이브·데모 빌드 및 산출물 검사, `npm run lint`가 통과했다.
- Playwright 빌드 모드 테스트 5건이 통과했다. 라이브 로그인 화면에서 문구가 없고, 로그인 후 앱과 데모 로그인에서 각각 기존 모드 표시가 보이는지 확인했다.
