# 2026-11-13 · 매출 조회의 일별 마감과 이용권 사용량을 상단 탭으로 이동

## 1. 배경 / 문제

일별 마감과 이용 지점별 이용권 사용량 버튼은 접힌 화면을 여는 컨트롤이라는 점이 겉으로 드러나지 않았다. 버튼과 조회 조건을 지나야 결과 탭이 보여 매출 조회에 어떤 화면이 있는지 처음 열었을 때 파악하기 어려웠다. [이슈 #110](https://github.com/OpenStudyService/OpenStudy-Frontend/issues/110)

## 2. 검토한 선택지

- 제목 아래에 여섯 화면을 같은 단계의 탭으로 배치한다.
- 매출 분석·일별 마감·이용권 사용량을 상단에 두고 매출 분석 안에 네 결과 탭을 배치한다.

## 3. 결정 및 이유

여섯 화면을 모두 상단 탭에 배치하기로 했다. 화면 이름과 현재 선택을 처음부터 보여 주고 각 화면에 한 번의 선택으로 접근할 수 있다. 좁은 화면에서는 탭을 줄바꿈해 마지막 탭도 처음부터 보이게 한다. 조회 기준 차이는 각 탭 아래에 그 화면이 사용하는 조건을 표시해 드러낸다.

## 4. 구현 내용

- 기존 네 결과에 일별 마감과 이용권 사용량을 추가했다. 새 주소는 `view=daily-closings`와 `view=pass-usage`를 사용한다. 탭 이동은 `view`만 갱신한다.
- 일별 마감은 자체 입력과 조회를 사용한다. 이용권 사용량은 날짜·이용 지점·상품 유형·상품 분류를 공유 URL에서 읽는다. 이용량에 적용되지 않는 결제 관련 조건은 매출 탭에서 다시 표시한다.
- 일별 마감과 이용권 사용량을 각각 열었을 때 조회한다. 매출의 기본 기간 표시와 두 화면의 기존 요청·권한·CSV 계약을 유지한다.

## 5. 검증 결과

- 관련 Vitest 3개 파일, 44개 시험 통과. 새 탭 주소, 잘못된 매출 조건으로부터 일별 마감 분리, 사용량 요청 및 CSV 조건, 기존 조회 조건 유지를 확인했다.
- 타입 검사, 린트, 전체 Vitest 87개 파일·771개 시험(`npm test -- --maxWorkers=4`), live·MSW 빌드 및 산출물 검사 통과.
- Chrome Playwright MSW 데모 2개 시험 통과. 별도 포트 16411에서 1440·1024·390px의 첫 화면에 여섯 탭이 모두 들어가는지 확인했다. 키보드·클릭 전환, 새로고침 후 사용량 탭 유지, 매출 조건 복원과 일별 마감 접근을 확인했다.
- `graphify update .`로 코드 그래프를 갱신했다.

## 6. 남은 작업 / 보류 사항

- 브라우저 검증은 Chrome MSW 데모에서 수행했다. 실제 API와 다른 브라우저는 미검증이다.
