# 2026-11-17 스터디룸·스터디룸 예약·사물함 목록을 공통 목록 레이아웃으로 정리

## 1. 배경 / 문제

- 같은 날 시설·고객 문의·공지 목록을 공통 목록 레이아웃으로 정리했다([2026-11-17-collaboration-list-layout.md](2026-11-17-collaboration-list-layout.md)). PR을 올리기 전에 같은 문제가 있는 화면이 더 있는지 점검했다.
- 공통 목록 컴포넌트를 쓰지 않는 표 15개 파일을 확인했다. 그중 수정 전 시설 목록과 같은 구조를 가진 곳은 다음 3곳이었다.
  - 스터디룸 목록: 첫 열이 테두리 있는 `Button`이고, 공통 표 스타일 대신 직접 만든 카드·필터·`Pager`를 쓴다.
  - 스터디룸 예약 목록 보기: 첫 열이 `Button`이고, 표 스타일과 하단 페이지 영역이 공통과 다르다.
  - 사물함 목록: 첫 열 버튼은 테두리가 없지만 링크로 보이지 않는다. 표 스타일과 하단 페이지 영역이 공통과 다르고, 등록 버튼이 제목 영역에 있다.
- 업무, 채널 관리, 공통 목록 페이지, 근무표는 공통 컴포넌트를 쓰지 않지만 `data-table`과 `cell-link`를 이미 써서 화면은 같다. 분석 표, 히트맵, 감사 로그 상세, 이용권 원장 대조는 목록이 아닌 보고서·상세 표다. 이 두 묶음은 대상에서 뺐다.

## 2. 검토한 선택지

- 이번 PR에 포함하거나 별도 PR로 분리할 수 있었다. 사용자가 이번 PR에 포함하기로 결정했다.
- 스터디룸 예약은 주간 달력과 목록 보기를 한 카드 안에서 전환한다.
  - 화면 전체를 `ListTable`로 감싸면 달력 보기와 맞지 않는다.
  - 그래서 필터 바만 공통 `ListFilters`로 바꾸고, 표·빈 상태·하단 페이지 영역은 목록 보기에만 적용했다.

## 3. 결정 및 이유

- 세 목록 모두 회원 목록(공통 목록의 기준 형태)과 같은 구조로 맞췄다. 카드 → 필터 바(등록 버튼은 오른쪽) → 표 → 하단 페이지 영역 순서다.
- 사물함은 등록·요금 일괄 적용 버튼을 제목 영역에서 필터 바 오른쪽으로 옮겼다. 다른 목록에서 등록 버튼이 필터 바 오른쪽에 있기 때문이다.
- 열 이름, 정렬 기준, 조회 로직, 행 클릭 동작은 바꾸지 않았다.

## 4. 구현 내용

- `src/features/rooms/RoomPages.tsx`
  - 스터디룸 목록: `ListCard`·`ListFilters`·`ListTable`·`ListFooter`로 교체하고, 첫 열을 `cell-link`로 바꿨다.
  - 스터디룸 예약: 필터 바를 `ListFilters`로 바꾸고, 목록 보기를 `ListTable`·`ListFooter`로 교체했다. 잘못된 조회 기간 안내는 `ListTable`의 `state`로 표 안에 표시한다. 달력 보기의 로딩·오류·달력 표시는 그대로 두었다.
  - 더 쓰이지 않는 `ReservationTable` 함수와 `current` 변수를 제거했다.
- `src/features/lockers/Lockers.tsx`
  - 목록을 `ListCard`·`ListFilters`·`ListTable`·`ListFooter`로 교체하고, 사물함 번호 셀을 `cell-link`로 바꿨다.
  - 등록·요금 일괄 적용 버튼을 필터 바 오른쪽으로 옮겼다.
  - 행 전체 클릭으로 상세를 여는 기존 동작은 유지했다.
