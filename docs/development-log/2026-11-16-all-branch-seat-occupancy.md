# 2026-11-16 지점별 실시간 좌석 비교 결과의 열 이름

## 1. 배경 / 문제

- 백엔드가 기획서 핵심 질문 2번("현재 지점별 사용 중인 좌석이 몇 개야?")에 지점별 비교 결과(`branchSeats`)를 반환하도록 바뀐다.
- 이 결과의 열(`occupied`, `available`, `free`, `blocked`, `occupied_pct`)에 한국어 이름이 없으면 표 머리글이 영어 별칭으로 보인다.

## 2. 결정 및 이유

- 막대그래프와 표는 기존 렌더러로 그릴 수 있어서 화면 코드는 바꾸지 않았다.
- 등록 분석 열 이름 표(`ANALYSIS_COLUMN_LABELS`)에만 다섯 열을 추가했다.

## 3. 구현 내용

- `domainlens.ts`: 이용 중, 운영 좌석, 빈자리, 차단, 점유율 이름을 추가했다.
- `domainlens-views.test.tsx`: 지점별 좌석 표가 한국어 머리글과 "86.4%" 형식으로 그려지는지 확인하는 테스트를 추가했다.

## 4. 검증 결과

- `npm run typecheck`, `npm run lint`, `npm test`(860개), `npm run build` 통과.
- 실제 화면 확인: live 모드에서 기획서 질문을 입력해 7개 지점의 점유율 막대그래프와 표를 확인했다.
  - 표 머리글: 지점, 이용 중, 운영 좌석, 빈자리, 점유율.

## 5. 남은 작업 / 보류 사항

- 백엔드 PR(같은 브랜치 이름 `feature/all-branch-seat-occupancy`)과 함께 병합해야 한다.
