# 2026-11-16 주간 스터디룸 예약 달력

## 배경과 결정

- 기존 예약 달력은 날짜별 카드에 예약을 나열했고, 전체 지점에서는 지점을 선택하기 전까지 일정이 보이지 않았다.
- 한국 시간 기준 월요일부터 일요일까지 7열을 두고 시간축에 예약 블록을 배치했다. 시작 시각은 블록의 위치, 예약 길이는 높이로 표시한다. 시간이 겹치는 예약은 같은 요일 안에서 나란히 놓는다.
- 전체 지점은 기존 지점별 달력 API 응답을 모아서 표시한다. 지점별 휴무를 구분하고, 일정의 상세 보기와 목록에서의 기간·상태 조회를 지원한다. 좁은 화면에서는 시간축을 고정하고 날짜 열을 가로로 스크롤한다.

## 검증

- 예약 화면 관련 테스트 30건, 전체 프런트엔드 테스트 860건, TypeScript 검사, ESLint, 실제 API용 빌드를 통과했다. 전체 지점 조회, 한국 시간 기준 주 경계, 같은 시각의 예약 배치, 주 이동을 회귀 테스트에 포함했다.
- 로컬 Vite 서버가 새 달력 코드를 제공하는 것을 확인했다. Windows 브라우저 제어 도구가 URL 확인 단계에서 중단되어 렌더링 검증은 끝내지 못했다.
- 관련 작업 [스터디룸 설정·예약 API 연결 #23](https://github.com/OpenStudyService/OpenStudy-Frontend/issues/23)
