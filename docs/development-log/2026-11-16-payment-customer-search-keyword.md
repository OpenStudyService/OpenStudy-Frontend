# 2026-11-16 · 결제 관리 고객 검색어 전달

## 배경 / 문제

결제 관리에서 고객을 검색하려면 모달을 먼저 열어야 했다. 고객 이름이나 회원번호를 알고 있는 사용자가 필터바에서 입력을 시작할 수 있도록 검색창을 추가했다.

## 결정 및 구현

- 고객 검색 버튼 왼쪽에 검색창을 배치했다. Enter를 누르거나 검색 버튼을 클릭하면 입력한 검색어로 모달의 첫 페이지를 조회한다.
- 입력 중에는 요청을 보내지 않는다. 한글 조합 중 Enter는 입력 조합을 마치는 동작으로 처리한다.
- 모달은 열릴 때 검색창으로, 닫힐 때 모달을 연 필터바 입력이나 버튼으로 초점을 돌려준다.

## 검증 결과

- 결제 및 공용 고객 선택 관련 Vitest 12개 파일, 155개 테스트 통과. Enter·버튼 검색, 첫 페이지 조회, 한글 조합 중 Enter, 초점 복귀를 확인했다.
- 타입 검사, 린트, `git diff --check` 통과.
- Chrome Mock 화면의 1440px와 390px에서 검색창과 버튼의 순서, Enter 검색 결과, 모달을 닫은 뒤 초점 복귀를 확인했다.

## 남은 검증

- 전체 테스트와 운영 API 검증은 실행하지 않았다.
