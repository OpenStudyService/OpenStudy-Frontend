# 2026-11-13 공용 상태 배지 색상

## 배경 및 결정

관리 메뉴 점검을 확대하면서 승인 대기와 비활성이 활성 상태와 같은 초록으로 표시되는 곳을 확인했다. 여러 화면에서 같은 라벨을 사용하므로 공용 배지의 기본 색상 규칙에 전체 문구가 일치하는 경우를 추가했다. 화면에서 색상을 명시하면 그 설정을 우선하고, 등록된 라벨과 일치하지 않으면 기존 규칙을 사용한다.

## 구현

- 초대·승인, 직원 상세의 지점 소속, 상품 분류와 직원 목록에 해당하는 승인 대기·비활성을 노랑으로 표시한다.
- 좌석·사물함의 사용 가능은 초록, 사용 중은 노랑, 운영 중단은 빨강으로 표시한다. 같은 상태 문구를 쓰는 룸 관리에도 동일하게 적용된다.
- 업무 우선순위의 높음은 노랑, 긴급은 빨강으로 표시한다. 홈과 업무 목록의 기한 초과 표시를 빨강으로 지정하고 업무 상세에도 같은 표시를 추가했다.
- 이용권 목록·상세와 회원의 보유 이용권에서 환불을 결제 관리와 같은 노랑으로 표시한다.

## 검증

- 공용 배지의 색상 및 명시적으로 지정한 색상 우선 적용을 검증했다. 업무 목록과 상세에서 높음·긴급 및 기한 초과 클래스도 확인했다.
- 타입 검사, 린트, 운영용 빌드와 빌드 검사가 통과했다. 전체 테스트 재실행 중 AI 화면 테스트 한 건이 5초 제한을 넘겼다. 해당 파일을 단독으로 실행해 6건 통과를 확인했고, `npm test -- --maxWorkers=4`에서 전체 835건이 통과했다.
- 운영 환경의 실제 화면은 확인하지 않았다.
