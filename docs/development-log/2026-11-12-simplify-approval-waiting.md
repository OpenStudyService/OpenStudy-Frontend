# 2026-11-12 직원 승인 대기 화면 간소화

## 배경과 결정

승인 대기 화면에는 상태 새로고침 버튼과 마지막 조회 시각이 표시됐다. 직원이 최신 결과를 확인할 때는 브라우저의 새로고침을 사용할 수 있어, 화면에서는 그 동작을 안내한다. 화면 진입과 브라우저 새로고침에 맞춰 조회하는 기존 정책을 적용한다.

## 구현

- 승인 대기 화면에서 전용 새로고침 버튼과 조회 시각을 제거했다. 조회 오류의 다시 시도와 승인 후 다시 로그인은 기존 동작을 사용한다.
- 갱신 정책과 브라우저 시나리오를 승인·반려 후 페이지를 다시 여는 흐름에 맞췄다.

## 검증

- 전체 Vitest 757개, ESLint, 타입 검사와 운영 모드 빌드를 통과했다.
- Chrome 모의 API 초대 테스트 2개가 통과했다. 승인 대기 화면에 버튼과 시각이 표시되지 않고, 브라우저 새로고침 후 승인 확인과 재로그인이 가능한 흐름을 확인했다.
- 실제 서버의 반려 후 새로고침 시나리오는 테스트 코드를 갱신했고 이번 작업에서 실행하지 않았다.
