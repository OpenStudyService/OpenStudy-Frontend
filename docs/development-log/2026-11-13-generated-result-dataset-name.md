# 2026-11-13 AI 생성 결과의 CSV 데이터셋 이름

## 1. 배경 / 문제

- #122 브라우저 확인에서, 생성 결과 카드의 CSV 다운로드 옆 데이터셋 이름이 `q0`로 보였다.
- 원인: CSV 목록은 데이터셋을 쓰는 화면 컴포넌트의 제목(`options.title`)을 이름으로 쓰고, 없으면 데이터셋 ID를 쓴다. 생성 결과의 화면 명세는 서버 컴파일러가 만들어 제목이 없고, 데이터셋 ID는 컴파일러가 붙인 `q0`이다.
- 사용자 요청으로 당시 함께 발견한 문제들(백엔드: 빈 context, CSV 열 이름 `d0`·`m0`, CSV 조건의 환불 기준)과 함께 처리했다. 백엔드 수정은 별도 PR이다.

## 2. 검토한 선택지

- 백엔드가 생성 화면 명세에 제목을 넣는다: 컴파일러(엔진) 변경이 필요하다.
- 화면이 생성 결과의 제목(`parsed.title`, 예: "지점별 결제 승인액")을 이름으로 쓴다(선택). 이미 QuerySpec에서 만든 제목이 있다.

## 3. 결정 및 이유

- 생성 결과에 데이터셋이 하나면 결과 제목을, 여럿이면 "결과 제목 (1)"처럼 번호를 붙인다.
- 등록 분석 결과는 기존대로 컴포넌트 제목, 없으면 데이터셋 ID다. 등록 분석에도 제목 없는 데이터셋(`basisContrast` 등)이 ID로 보이지만, 이번 범위(생성 결과)가 아니어서 두었다.

## 4. 구현 내용

- `AiExports.tsx`: 생성 결과의 CSV 이름 대체값
- 테스트: `generated-results.test.tsx` 2개 추가. `Ai.test.tsx`의 생성 결과 테스트 2개는 결과 카드 제목(h3)을 찾도록 바꿨다. CSV 이름(h4)도 같은 문구가 되었기 때문이다.
