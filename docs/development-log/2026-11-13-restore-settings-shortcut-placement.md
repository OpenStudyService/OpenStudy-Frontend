# 설정 바로가기의 기존 위치 복원

## 1. 배경 / 문제

헤더에 설정 바로가기를 추가한 뒤, 사용자가 기존 위치를 확인해 다시 배치해 달라고 요청했다. [PR #119](https://github.com/OpenStudyService/OpenStudy-Frontend/pull/119)

## 2. 검토한 선택지

직전 커밋의 공통 헤더 배치와 #111 구현 전 코드의 빠른 탐색 배치를 비교했다. 이전 코드는 데스크톱 왼쪽 레일에서 아바타 바로 위, 모바일 하단 탐색에서 마지막 항목에 설정을 표시했다.

## 3. 결정 및 이유

이미 익숙한 위치에서 설정을 열 수 있도록 두 빠른 탐색 바로가기를 복원한다.

## 4. 구현 내용

헤더의 별도 바로가기를 제거하고 데스크톱 레일과 모바일 하단에 톱니바퀴 아이콘과 **설정** 문구를 표시한다. 두 바로가기 모두 현재 지점의 개인 설정으로 이동하며 현재 페이지에서 활성 스타일을 적용한다.

## 5. 검증 결과

타입 검사, 린트와 관련 Vitest 22개를 통과했다. Chrome MSW에서 OWNER·지점 관리자·일반 직원의 데스크톱 레일과 모바일 하단 바로가기 노출, 클릭 이동 및 현재 페이지 상태를 확인했다.

## 6. 남은 작업 / 보류 사항

이번 후속 변경은 관련 테스트와 브라우저 시나리오를 다시 실행했다.
