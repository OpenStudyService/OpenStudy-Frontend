# 2026-11-12 · 공통 업무 화면의 새로고침 표시 제거

## 배경과 결정

[Frontend #77](https://github.com/OpenStudyService/OpenStudy-Frontend/issues/77)에서 업무 화면의 수동 재조회와 마지막 성공 조회 시각을 도입했다. 이번에는 우측 상단을 간결하게 정리하기 위해 공통 새로고침 버튼과 조회 시각을 제거했다. 현재 메뉴를 다시 누르는 동작으로 같은 조건에서 재조회할 수 있으므로 별도 버튼을 추가하지 않았다.

## 구현

- 공통 레이아웃에서 버튼과 조회 시각을 제거하고, 이전 조회 결과를 표시하는 오류 안내가 있을 때만 해당 영역을 렌더링한다.
- 공통 시각 표시 전용 캐시 구독과 집계를 제거했다. 메뉴 재클릭에 따른 명시적 재조회와 승인 대기 화면의 승인 상태 새로고침 및 조회 시각 표시는 유지했다.
- [프론트엔드 화면 갱신 정책](../design/data-refresh-policy.md)과 Backend의 ADR-COM-001을 갱신했다.

## 검증

- `npm run typecheck`, `npm run lint`, `npm test` 통과. 전체 Vitest 86개 파일, 753개 테스트가 통과했다.
- `npm run build`의 프로덕션 빌드와 live 산출물 검사 통과.
- 공통 레이아웃 테스트에서 버튼·시각 미표시, 유휴·포커스·재연결 시 요청 미발생, 재조회 실패 시 이전 결과 유지와 복구를 확인했다.
- 로컬 Chrome의 Playwright Mock 시나리오 2개가 통과했다. 업무 메뉴 재클릭 시 동일 조건의 GET이 발생하고, 승인 대기 화면에서는 조회 시각과 새로고침을 사용할 수 있음을 확인했다. 로컬 포트 충돌을 피해 별도 포트에서 실행했다.
- 실제 백엔드와 클라우드 배포 화면은 검증 범위에 포함하지 않았다.
