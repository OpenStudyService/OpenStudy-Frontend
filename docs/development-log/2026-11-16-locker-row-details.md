# 2026-11-16 사물함 행에서 상세 열기

## 배경과 결정

공간 관리의 사물함 목록에서는 번호 버튼을 눌러야 상세를 열 수 있었다. 버튼의 크기만 키우면 다른 셀에서는 여전히 상세를 열 수 없으므로, 행 전체를 클릭 영역으로 바꾸고 기존 상세 패널을 재사용했다.

## 구현

- 번호는 일반 텍스트처럼 표시하고, 행에 마우스를 올리면 클릭할 수 있음을 표시한다.
- 번호의 기본 버튼 요소는 키보드 진입점으로 유지한다. 행의 다른 셀을 클릭해도 이 진입점에 포커스를 옮긴 뒤 상세를 열어, 패널을 닫으면 같은 사물함으로 돌아갈 수 있게 했다.
- 기존 상세 URL, 목록의 필터·정렬·페이지 처리, 배정·수정 작업은 그대로 사용한다.

## 검증

- 타입 검사, ESLint, 관련 Vitest 29건, 전체 Vitest 860건, 운영용 빌드 및 빌드 검사 통과.
- Chrome 모의 API 테스트 2건 통과. 번호가 아닌 셀에서 상세 열기, 닫은 뒤 번호로 포커스 복귀, Enter로 재열기, 기존 등록·수정·상태 변경 흐름을 확인했다.
- `graphify update .`로 작업공간 그래프를 갱신했다. 운영 서버를 연결한 브라우저 검증은 수행하지 않았다.
