# 2026-11-16 · 고객 검색 결과 페이지 이동

## 배경 / 문제

결제 관리의 고객 검색 모달은 검색창 옆에서 한 페이지씩 이동할 수 있었다. 결과가 여러 페이지일 때 원하는 페이지로 바로 이동할 수 없었다.

## 결정 및 구현

- 공용 `Pagination`에 현재 페이지, 전체 페이지 수, 이동 콜백을 전달한다. 현재 페이지가 속한 구간의 번호를 최대 10개 표시하며, 이전·다음은 한 페이지씩 이동한다. 현재 페이지는 색과 접근성 속성으로 표시한다.
- 결제 관리 모달에서 결과 표 아래에 적용했다. 결과를 스크롤해도 페이지 이동은 모달 하단에 보인다. 결과가 한 페이지에 들어가면 결과 수만 표시한다.
- 같은 검색어의 다른 페이지를 조회하는 동안 페이지 이동 위치와 전체 페이지 수를 유지한다. 결과 표에는 새 페이지가 도착할 때까지 로딩 상태를 표시한다.

## 검증 결과

- 관련 Vitest 13개 파일, 158개 테스트 통과. 10개 번호 구간, 직접 이동, 이전·다음, 마지막 구간과 버튼 비활성, 모달 안의 표 아래 배치와 선택 흐름을 확인했다.
- Chrome Mock 화면의 1440px·390px에서 모달 하단의 번호 표시와 줄바꿈, 번호 선택, 10→11페이지 이동, 마지막 페이지 경계를 확인했다.
- 타입 검사, 린트, `git diff --check` 통과.
