# 등록 진입 버튼의 + 아이콘 통일

## 1. 배경 / 문제

회원 관리의 회원 등록에는 + 아이콘이 있지만 상품 등록에는 없어 메뉴별 표현이 달랐다. 사용자가 상품 이외의 누락도 조사하고 수정해 달라고 요청했다. 최신 main 7bc6f8b에 앞선 버튼 색상 PR #151이 반영된 것을 확인하고 `fix/create-button-icons` 브랜치를 생성했다.

## 2. 검토와 결정

TSX의 공통 Button·네이티브 button·Link에서 등록·추가·초대·새 항목 열기와 연결된 콜백을 조사했다. [기존 등록 버튼 배치 기록](2026-11-12-align-create-buttons-with-filters.md)도 확인했다.

목록에서 등록 화면을 여는 버튼은 회원 등록과 같은 기존 `Icon`의 plus, 크기 16px로 통일한다. 제출 버튼은 기존 회원 등록 폼과 같은 텍스트 방식으로 유지한다. 새 공통 버튼 컴포넌트나 아이콘 라이브러리는 추가하지 않았다.

## 3. 조사 결과와 구현

| 등록 진입 버튼 | 결과 |
| --- | --- |
| 상품 등록 | plus 추가 |
| 지점 등록 | plus 추가 |
| 좌석 등록 | plus 추가 |
| 근무 등록 | plus 추가 |
| 권한 프리셋 등록 | plus 추가 |
| 채널 등록 | plus 추가. 현재 메뉴는 비활성 상태이며 컴포넌트 표현만 맞추고 메뉴·API를 활성화하지 않음 |
| 회원·업무·사물함·스터디룸·예약 등록 | 이미 plus 있음 |
| 시설·문의·공지 등록 | 공통 목록 버튼에 이미 plus 있음 |
| 직원 초대·공통 리소스 등록 | 이미 plus 있음 |
| AI 새 대화 | 이미 plus 있음. 작은 도구 모음의 기존 14px 크기는 유지 |

분류·시설 유형·휴무일·상품 등의 실제 등록 제출, 체크 항목의 직접 추가, 결제·유료 배정 등 별도 업무 실행은 목록 등록 진입과 구분했다. 시설 유형의 네이티브 details 열기도 목록 등록 버튼으로 간주하지 않았다.

6곳 모두 기존 문구·클릭·권한·disabled·패널 연결은 그대로 두고 숨김 장식 아이콘만 추가했다. 아이콘은 접근성 이름에 더해지지 않는다.

## 4. 검증 결과

- 관련 Vitest 6개 파일·82개 테스트 통과.
- 전체 Vitest 96개 파일·889개 테스트 통과.
- 타입 검사·린트·diff 검사 통과.
- live 빌드 및 산출물 검사 통과. 기존 500kB 초과 청크 안내가 발생했으며 빌드는 성공했다.
- Chrome MSW 5개 시나리오 통과. 상품·지점·좌석·근무·프리셋 각각 1440·390px에서 장식 아이콘 표시, 기존 접근성 이름, 화면 안 버튼 배치, 등록 패널 열기·닫기를 확인했다.
- `graphify update .` 코드 그래프 갱신 완료. 기존 SQL 파서 부재 안내가 있었으며 SQL은 변경하지 않았다.

## 5. 남은 작업 / 보류 사항

실제 Backend·운영 환경은 검증하지 않았다. 비활성 채널 관리의 브라우저 경로는 열지 않았으며 관련 컴포넌트 테스트로 회귀를 확인했다. 작업 브랜치 push와 PR 생성 후 사용자 병합 대기로 둔다.
