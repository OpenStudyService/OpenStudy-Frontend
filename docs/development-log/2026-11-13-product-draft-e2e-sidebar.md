# 상품 등록 초안 E2E의 운영 메뉴 진입 수정

PR #124의 사용성 CI에서 상품 등록 초안 테스트가 홈의 기본 접힌 메뉴에서 상품 관리 링크를 찾지 못했다. 테스트에서 상단 메뉴를 먼저 열고 운영 메뉴 안의 상품 관리 링크를 선택하도록 수정했다. 데모 사장님 계정이 로그인 후 전체 지점으로 이동하므로 `/app/all/products`를 확인한다. 상품 등록 초안의 닫기·뒤로가기·새로고침 보호 검증은 유지했다.

상품 등록 초안 테스트 단독 실행과 최종 `npm run test:e2e:usability` 37개가 통과했다. 첫 전체 실행에서는 별도의 회원 관리 테스트가 로딩 시간 초과로 실패했고, 단독 재실행과 최종 전체 실행에서는 통과했다. 데모 빌드로 시도한 전체 실행에서는 개발 서버의 모듈을 가져오는 방 목록 테스트 한 건이 실패했으며, 최종 개발 서버 실행에서는 통과했다.
