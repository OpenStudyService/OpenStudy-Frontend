# 홈·채팅에서 왼쪽 사이드바 펼치기

## 배경과 결정

기본 접기 이후 상단 메뉴 버튼이 오른쪽 패널에 운영 메뉴를 표시했다. 사용자 피드백에 따라 데스크톱에서는 기존 왼쪽 사이드바를 레일 옆에 펼쳐, 업무 화면과 같은 위치에서 지점과 운영 메뉴를 찾을 수 있게 했다. 좁은 화면에서는 본문 폭을 유지하기 위해 기존 메뉴 대화상자를 왼쪽에 배치했다.

## 구현

- 데스크톱에서는 상단 버튼을 다시 누르거나 메뉴에서 Escape를 눌러 사이드바를 접을 수 있다. 화면·지점·반응형 모드가 바뀌면 메뉴를 닫는다.
- 태블릿 메뉴는 레일 옆에서, 모바일 메뉴는 화면 왼쪽에서 열린다. 업무·설정 등의 메뉴 동작은 기존 레이아웃을 따른다.
- 브라우저 테스트에서 메뉴 위치를 확인하고, 데스크톱에서는 펼쳤을 때 고정 사이드바가 본문 너비를 조정하는지 확인한다.

## 검증 결과

- TypeScript, ESLint, 전체 Vitest 814개, 운영·데모 빌드와 산출물 검사 통과.
- 데모 빌드를 사용한 Chrome 테스트 5개 통과. 1100px·1099px·390px에서 메뉴 위치, 접기, 지점 변경과 뒤로가기, 키보드 포커스를 확인했다. 개발 서버로 실행한 초기 검사에서는 일부 페이지의 로딩 시간이 초과됐다.
- 프론트엔드 Graphify AST 그래프를 갱신했다. 실제 운영 환경과 모바일 실기기는 미검증이다.
