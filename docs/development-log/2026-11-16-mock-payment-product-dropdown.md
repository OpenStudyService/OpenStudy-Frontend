# 2026-11-16 · Mock 결제 판매 상품 드롭다운

## 배경 / 문제

Mock 결제 사이드바에서는 판매 지점을 고른 뒤 상품 검색과 페이지 이동을 거쳐야 했다. 지점의 판매 상품을 한 드롭다운에서 탐색할 수 있도록 입력을 줄였다.

## 결정 및 구현

- 판매 지점을 기준으로 `판매 중` 상태의 상품을 이름순으로 조회한다. API의 페이지 단위는 유지하고 공용 목록 조회 로직으로 전체 페이지를 읽어 드롭다운에 모은다.
- 지점을 변경하면 이전 상품 선택을 초기화한다. 지점 선택 전, 조회 중, 조회 실패, 빈 목록 상태는 드롭다운에서 구분한다.
- 판매 기간과 한도는 기존 결제 검증을 적용한다. 목록의 판매 상태와 결제 가능 여부는 상품 계약에 따라 판단한다.
- 고객 검색 옆 안내를 걷어내고, Mock 결제 검색창에 `고객 이름·회원번호·연락처`를 표시한다.

## 검증 결과

- 관련 Vitest 25개 파일, 298개 테스트 통과. 두 API 페이지에 걸쳐 상품 101개를 표시하고 중지 상품과 타 지점 상품을 제외하는 시나리오를 확인했다.
- 타입 검사, 린트, `git diff --check` 통과.
- Chrome Mock 환경 390px에서 판매 지점 선택 전후의 드롭다운, 전체 결과 수, 지점 변경 시 선택 초기화, 고객 검색 안내를 확인했다.

## 남은 검증

- 전체 테스트, 실제 백엔드 연동 검증은 실행하지 않았다.
