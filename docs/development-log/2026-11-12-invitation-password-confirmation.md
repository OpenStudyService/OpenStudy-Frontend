# 2026-11-12 신규 직원 초대 비밀번호 확인

## 배경과 결정

신규 직원은 초대를 수락할 때 비밀번호를 한 번 입력했다. 오타가 있어도 수락이 진행되면 직원이 이후 로그인할 때까지 알아차리기 어렵다. 신규 계정 폼에서 한 번 더 입력받아 수락 전에 두 값이 일치하는지 확인한다.

## 구현

- 새 계정 초대에 비밀번호 확인란을 표시한다. 값이 다르면 확인란 아래에 오류를 보여 주고 입력값을 유지한다. 확인값은 화면에서 비교하는 데만 사용한다.
- 기존 계정의 로그인·초대 수락에는 기존 입력 흐름을 적용한다.

## 검증

- Vitest에 불일치 시 수락 요청이 전송되지 않고, 확인값을 수정하면 기존 API 요청 형식으로 수락되는 회귀 검증을 추가했다.
- Chrome 모의 API 시나리오에서 불일치 표시, 확인값 수정 후 수락, 만료 링크 안내를 확인했다.
- 전체 Vitest 757개, Chrome 초대 시나리오 2개, ESLint, 타입 검사와 운영 모드 빌드를 통과했다.
- 실제 수신 메일과 운영 서버를 통한 수락은 이번 변경에서 검증하지 않았다.
