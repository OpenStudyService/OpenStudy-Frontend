# 2026-11-12 · 업무 등록 버튼을 검색·필터 바에 배치

[기존 등록 버튼 배치 작업](2026-11-12-align-create-buttons-with-filters.md)은 여섯 화면을 대상으로 했다. 업무 관리도 같은 기준을 적용해, 제목 옆의 업무 등록 버튼을 검색·필터 바 맨 오른쪽으로 옮겼다. 기존 등록 권한과 패널 열기 동작을 유지했다.

타입 검사, 린트, 관련 Vitest 51개가 통과했다. Chrome과 Mock API를 사용한 Playwright 검증에서 업무 관리를 포함한 일곱 화면의 데스크톱·모바일 오른쪽 정렬, 등록 패널 열기·닫기, 조회 조건 유지를 확인했다.
