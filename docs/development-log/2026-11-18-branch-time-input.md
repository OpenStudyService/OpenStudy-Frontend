# 지점 운영시간을 시·분으로 입력

## 1. 배경 / 문제

지점 등록·수정 사이드 패널에서 운영 시작과 종료를 자정부터의 분 숫자로 입력해야 했다. 사용자가 직접 시간을 환산해야 하므로 시·분으로 설정할 수 있게 해 달라는 요청을 받았다. 기존 지점 목록 변경 기록과 관련 PR #119를 확인했다.

## 2. 검토한 선택지

브라우저의 기본 `input type="time"`을 검토했다. 시·분 선택과 키보드 입력을 제공하고 별도 라이브러리가 필요하지 않아 채택했다. 기본 시간 입력은 24:00 이후를 표현할 수 없으므로 종료 날짜를 별도로 선택하도록 했다.

## 3. 결정 및 이유

공통 `TimeInput`에서 HH:MM 값과 API의 분 숫자를 변환한다. API 계약과 운영시간 검증 규칙을 유지하면서 사용자의 분 환산을 없앤다. 종료는 당일·다음 날을 구분하며, 기존 상한인 다음 날 24:00도 별도 선택할 수 있다. 기본 24시간 운영은 시작 00:00, 종료 다음 날 00:00으로 표시한다.

기본 입력의 표시 방식은 브라우저와 운영체제의 지역 설정에 따르며 값은 HH:MM 형식이다. [MDN 시간 입력 문서](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/time)

## 4. 구현 내용

- 지점 등록과 수정의 요일별 시작·종료에 공통 시간 입력을 적용했다.
- 종료 날짜 선택으로 익일 운영을 표현하며 다음 날 24:00을 선택하면 시간은 00:00으로 고정된다.
- 시간을 지웠다가 다시 입력해도 선택한 종료 날짜를 유지한다.
- 휴무 전환 시 시작·종료를 null로 저장하고 해제 시 기존 24시간 기본값으로 복원한다.
- 입력 라벨에서 분 단위를 제거하고 자정 이후 종료와 24시간 운영 안내를 추가했다.
