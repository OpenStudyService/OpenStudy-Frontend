# 업무 상세 버튼의 역할과 강조 단계 구분

## 배경 / 문제

[업무 상세 주요 버튼 후속 수정](2026-11-18-task-detail-primary-buttons.md)에서 수정·진행·완료를 모두 주요 색상으로 표시했다. 사용자는 서로 다른 역할의 버튼은 스타일도 달라야 한다고 지적했고, 색상만 나눈 안에 대해서도 디자인 개선을 요청했다.

## 검토한 선택지와 결정

수정은 기본 테두리, 진행은 연한 강조, 완료는 주요 색상인 안을 실제 화면에서 확인했다. 이어 역할을 더 명확하게 구분하기 위해 수정과 상태 변경을 별도 그룹으로 배치하고 아이콘을 추가했다. 별도 공통 variant를 늘리는 대신 기존 quiet·기본·primary를 재사용했다.

## 구현 내용

- 왼쪽에 quiet 스타일의 수정하기와 연필 아이콘을 배치했다.
- 오른쪽에 업무 상태 변경 그룹을 만들고, 진행하기·할 일로 변경은 테두리 버튼과 방향 아이콘, 완료하기는 primary와 체크 아이콘으로 구분했다.
- 실행 확인 화면도 같은 강조 단계를 사용한다. 항목 추가의 primary와 기존 삭제·취소 스타일은 유지한다.
- 색상 외에도 위치·그룹·아이콘으로 역할을 표현한다. 아이콘은 접근성 트리에서 숨기고 기존 버튼 이름과 이벤트·권한·disabled 조건을 유지했다.
- 이어 사용자가 체크리스트의 수정·삭제도 아이콘으로 바꿔 달라고 요청했다. 각 행의 오른쪽에 연필·휴지통 아이콘을 정렬하고 수정은 quiet, 삭제는 danger로 구분했다. 항목별 접근성 이름을 유지하고 title 설명을 추가했다. 편집 중에는 입력과 저장·취소 텍스트 버튼을 유지한다.

- 관련 Vitest: 2개 파일·41개 테스트 통과.
- `npm run typecheck`, `npm run lint`: 통과.
- Chrome MSW 최종 일회성 점검 1개 통과. 세 버튼의 실제 배경이 서로 다른지와 variant를 확인하고 1440·390px 캡처를 눈으로 검토했다. 체크리스트 아이콘의 접근성 이름·title 및 실제 수정 → 저장 → 삭제, 항목 추가 → 진행 → 완료 뒤의 버튼 표시·스타일과 동작도 확인했다.
- `git diff --check` 통과, `graphify update .` 코드 그래프 갱신 완료.
