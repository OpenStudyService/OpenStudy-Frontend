# 2026-11-17 · 회원 관리 페이지 번호 배치 확인

## 배경 / 문제

페이지 번호가 10개 단위로 고정되어 있어 11페이지로 넘어가면 10페이지 번호가 사라진다. 현재 페이지 주변 번호를 함께 보여주는 방식을 회원 관리에서 먼저 확인하기로 했다.

## 결정 및 이유

공용 페이지네이션에 현재 페이지를 기준으로 번호 범위를 계산하는 옵션을 추가하고, 회원 관리의 회원 목록과 보유 이용권 탭에서 활성화했다. 범위 계산을 한 곳에서 검증할 수 있고, 적용하는 화면은 호출부에서 결정할 수 있다.

## 구현 내용

- 가능한 경우 현재 페이지를 번호 10개 중 다섯 번째에 둔다. 예를 들어 전체 23페이지의 12페이지에서는 8~17을 표시한다.
- 첫 페이지나 마지막 페이지 근처에서는 범위를 조정해 최대 10개를 표시한다.

## 검증 결과

- 관련 Vitest 5개 파일, 93개 테스트 통과. 범위 중앙과 양 끝, 회원 관리 두 탭의 표시, 회원 검색 조건 유지와 기존 고정 묶음 동작을 확인했다.
- `npm run typecheck`, `npm run lint`, `git diff --check` 통과.
- Chrome에서 Mock 응답의 전체 건수를 460건으로 설정해 23페이지를 재현했다. 1440px과 390px에서 회원 목록과 보유 이용권의 12페이지가 다섯 번째에 있고, 13페이지 버튼을 누르면 번호 범위와 URL이 바뀌는 것을 확인했다.
- 전체 테스트, 빌드, 운영 API 검증은 실행하지 않았다.
