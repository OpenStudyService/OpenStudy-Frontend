# 2026-11-16 추천 질문 응답을 DomainLens 목업 형태로 표시

## 1. 배경 / 문제

- 추천 질문 응답이 `OpenStudy_DomainLens_v9-6_Final_Stage6.html` 목업과 달랐다.
  - 열 이름이 원시 별칭(`net_krw (KRW)`)으로 보였다.
  - 히트맵, 좌석, 예약, 업무 화면 아래에 표가 덧붙었다.
  - 막대는 세로형이었다.
- 백엔드가 이제 KPI 카드 데이터셋(`summaryCards`)과 패널 제목·보조 문구를 내려주므로, 프론트엔드가 이를 목업처럼 그려야 했다.

## 2. 검토한 선택지

- **기존 recharts 유지 + 가로 막대(`layout="vertical"`)**: PNG 내보내기가 recharts SVG에 의존하므로 차트 라이브러리를 유지했다.
- **CSS 막대 목록**: 목업과 더 비슷하게 만들 수 있지만 PNG 내보내기가 깨진다. 선택하지 않았다.

## 3. 결정 및 이유

- 컴포넌트 종류별 렌더러만 바꾸고, ViewSpec 레이아웃 조립 방식은 그대로 두었다.
- 카드·제목·열 구성은 백엔드 ViewSpec을 따른다.

## 4. 구현 내용

- `Charts.tsx`
  - KPI가 `columns` 바인딩이면 label/value/note 카드로 그린다(색상 4종).
  - BAR/RANKED_BAR/LINE을 하나로 묶었다.
    - 막대: 가로 막대, 값 라벨, 첫 막대 강조, 값 큰 순 정렬.
    - 선: 여러 계열과 범례.
  - 표 머리글은 단위 없이 열 이름만 쓴다.
  - 값 형식: KRW는 원, 단위가 있으면 숫자+단위, TIMESTAMP는 KST 날짜.
  - `_id` 열은 천 단위 구분 없이 표시한다.
  - 패널 머리에 `subtitle`을 표시한다.
- `domainlens.ts`: 등록 분석 열에 한국어 이름을 붙인다(`ANALYSIS_COLUMN_LABELS`).
- 화면 다시 작성
  - 히트맵: 요일 열 × 시간 행, 5단계 색, 피크 테두리, 범례.
  - 좌석 배치: 번호 타일.
  - 주간 예약: 7일 타일 + 선택일 예약 목록.
  - 긴급 업무: 업무·지점·기한·우선순위·상태 표.
  - 네 화면 모두 아래에 붙던 표를 없앴다.
- `styles.css`: 카드, 히트맵, 좌석, 주간 캘린더, 상태 배지, 결과 패널 안의 촘촘한 표 스타일을 추가했다.
