# 2026-11-16 근무표의 주간 시간 달력

## 배경과 결정

근무표는 직원별 행 안에 일정 카드를 나열해 하루 중 언제 근무하는지 비교하기 어려웠다. 예약 관리의 주간 달력처럼 월요일부터 일요일까지 날짜 열을 두고, 세로 시간축에서 시작 시각과 길이를 읽도록 했다. 두 화면은 날짜 경계, 겹치는 일정 배치, 가로 스크롤 처리를 공유한다.

## 구현

- 한국 시간 기준으로 패널에 일정을 배치한다. 같은 시간의 예정 근무와 실제 출퇴근을 나란히 놓고 색과 이름으로 구분한다. 주 안에서 자정을 넘는 일정은 날짜별로 나눠 표시한다.
- 이전 주, 이번 주, 다음 주 버튼과 날짜 선택으로 이동한다. 예정 근무를 선택하면 기존 상세가 열린다. 실제 출퇴근에는 서버가 확정한 실근무 분을 표시하고, 모의 환경의 승인 휴가는 날짜 제목 아래에 표시한다.
- 근무표 데이터의 조회 범위는 기존 주간 API 계약을 따른다. API는 그 주에 시작한 예정 근무와 실제 기록을 반환한다.

## 검증

- 전체 Vitest 859건, 타입 검사, ESLint, 운영용 빌드 및 빌드 검사 통과.
- Chrome 모의 API 테스트는 근무·근태·휴가·반응형 및 테마 8건과 예약·룸 관리 3건이 통과했다. 예약 테스트의 기존 ‘달력 보기’ 선택자를 현재 UI에 맞춰 수정하고, 목록에서 달력으로 돌아왔을 때 날짜 열이 표시되는지 확인했다.
- `graphify update .`로 작업공간 그래프를 갱신했다. 운영 서버를 연결한 브라우저 검증은 수행하지 않았다.
