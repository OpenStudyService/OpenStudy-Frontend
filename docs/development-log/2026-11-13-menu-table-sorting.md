# 2026-11-13 다른 메뉴의 테이블 열 정렬

## 배경 및 결정

회원 목록과 같은 방식으로 다른 메뉴에서도 열 제목을 눌러 정렬할 수 있도록 했다. 페이지가 나뉜 목록은 기존 API가 허용하는 기준을 사용해 필터링된 전체 결과를 정렬하고, 전체 데이터를 이미 받은 표는 표시할 행을 브라우저에서 정렬한다.

## 구현

- 지점명, 직원명, 초대 이름·수락 기한, 상품명·판매 금액, 결제 금액·일시, 보유 이용권 만료 일시, 입실 일시, 업무 기한·우선순위, 시설 이름·다음 점검일, 고객 문의 등록일을 열 제목 정렬에 연결했다.
- 채널 관리, 매출 상세·추세, 마감 조정 이력, 좌석 점유 추이, 회원별 이용권 원장의 일부 열에 정렬을 적용했다. 원장의 분과 원 단위 수치, 달력형 표와 서버가 고정 순서로 제공하는 목록은 기존 순서를 유지한다.
- 페이지가 있는 목록은 정렬을 바꾸면 검색 조건을 유지하면서 첫 페이지로 이동한다. 초대와 시설·문의의 모의 API도 페이지를 나누기 전에 정렬한다.

## 검증

- 전체 Vitest 813건, 린트, 타입 검사를 포함한 운영용 빌드가 통과했다.
- 결제 금액 제목의 양방향 전환과 첫 페이지 이동, 브라우저에서 숫자를 정렬할 때의 값 비교와 빈 값 처리를 테스트했다.
- 로컬 백엔드에서 새 제목 버튼에 연결된 정렬 요청 15개가 HTTP 200을 반환했다.

## 후속 작업

근태, 변경 이력, 스터디룸·사물함, 공지 등 페이지 순서가 서버에 고정된 목록과 각 API에 아직 없는 정렬 기준은 백엔드 계약 확장이 필요하다.
