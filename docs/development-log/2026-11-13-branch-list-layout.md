# 지점 관리에 공통 목록 레이아웃 적용

## 1. 배경 / 문제

지점 관리를 별도 메뉴로 옮긴 뒤에도 지점별 카드가 세로로 쌓여 있었다. 회원·상품 등 다른 관리 화면과 같은 구성으로 정리해 달라는 요청을 받았다. [공통 레이아웃 PR #114](https://github.com/OpenStudyService/OpenStudy-Frontend/pull/114) · [적용 사례 PR #116](https://github.com/OpenStudyService/OpenStudy-Frontend/pull/116)

## 2. 검토한 선택지

기존 카드에 검색 배치만 맞추는 방식과 공통 목록 컴포넌트로 표와 페이지 이동까지 통일하는 방식을 비교했다.

## 3. 결정 및 이유

지점의 기본 정보와 운영 상태를 한 행에서 비교할 수 있도록 공통 카드·필터·표·하단 페이지 이동을 재사용했다. 상품 목록처럼 수정 권한이 있는 사용자는 이름 셀에서 수정 화면을 열고, 휴무일 조회와 관리는 별도 열에서 진입한다.

## 4. 구현 내용

- 검색과 초기화, OWNER 전용 지점 등록을 필터 바에 모았다. 초기화는 지점 검색·페이지 파라미터만 제거한다.
- 표 안에 지점 정보와 로딩·오류·빈 상태를 표시한다. 기존 지점 등록·수정 및 휴무일 화면을 연결한다.

## 5. 검증 결과

- 타입 검사, 린트와 관련 Vitest를 통과했다.
- Chrome MSW에서 지점 등록·이름 셀로 수정 열기·검색 초기화·휴무일과 세 역할의 메뉴·권한을 확인했다. 1440·1024·390px에서 페이지 가로 넘침을 확인했다.
- `graphify update .`로 코드 그래프를 갱신했다.

## 6. 남은 작업 / 보류 사항

후속 변경의 관련 시험을 실행했다. 실제 Backend 연결과 전체 테스트·빌드는 다시 실행하지 않았다.
