# 2026-11-13 메뉴 테이블의 누락된 제목 정렬

## 배경 및 결정

기존 API가 지원하는 열만 정렬 버튼을 제공해 같은 표에서도 여러 제목을 눌러 정렬할 수 없었다. 서버가 지원하는 정렬은 기존 API를 사용한다. 그 외 데이터 열은 정렬을 선택했을 때 현재 필터의 결과를 최대 100건씩 읽어 브라우저에서 정렬한 뒤 화면 페이지를 나눈다.

## 구현

- 지점·직원·초대·상품·결제·보유 이용권·입퇴실·업무·시설·고객 문의의 빠진 데이터 열을 연결했다.
- 출퇴근·근무 목록, 변경 이력, 스터디룸·예약, 사물함, 공지, 매출 원장·상품 판매 순위 및 이용량 표에 제목 정렬을 추가했다.
- 휴무일 관리와 결제 상세처럼 작업 버튼만 있는 열, 주간 달력처럼 시간 배열이 의미를 갖는 표는 기존 방식을 사용한다.
- 프런트 정렬은 선택한 필터의 모든 페이지를 조회하므로 큰 목록의 첫 정렬과 페이지 전환에 여러 요청이 필요할 수 있다.

## 검증

- 서버의 두 번째 페이지에 있던 값이 정렬 후 화면의 첫 페이지에 나타나는 경우를 테스트했다.
- 로컬 API의 목록 16개에서 페이지 크기 100으로 조회가 성공했다. 운영 환경에서의 응답 시간은 검증하지 않았다.
- 전체 Vitest 814건과 린트, 타입 검사를 포함한 운영용 빌드가 통과했다.
