# 2026-11-13 · 매출 조회 필터 바 정리

## 1. 배경 / 문제

고급 필터가 별도 팝업으로 열렸고, 기본 조건과 지점 선택의 배치가 한눈에 들어오지 않았다.

## 2. 검토한 선택지

기존 팝업을 다듬거나 조회 조건 카드 안에 펼침 영역을 둘 수 있었다.

## 3. 결정 및 이유

카드 안에서 고급 필터를 펼치고 접는다. 펼친 동안에도 기본 조건을 같은 흐름에서 볼 수 있고, 접힌 상태에서도 적용된 고급 조건 수를 알 수 있다.

## 4. 구현 내용

- 기본 입력을 같은 높이로 정렬하고, 화면 폭에 따라 네 열 또는 두 열로 배치했다. 기간 안내와 기본 기간 버튼은 입력 아래에 모았다.
- 지점 선택은 줄바꿈되는 체크박스와 선택 색으로 정리했다.
- 고급 필터 전체는 Radix Collapsible을 사용한다. 결제 수단·상품 유형·환불 처리 지점의 개별 체크박스 드롭다운을 재사용한다.

## 5. 검증 결과

- 관련 Vitest 3개 파일·44개, 타입 검사, 린트, live·MSW 빌드 통과.
- Chrome MSW 데모에서 390·1024·1440px의 열림과 닫힘 화면을 확인했다. 카드 안 펼침, 키보드 닫기, 안쪽 드롭다운 선택, 가로 넘침 여부를 시험했다.
- `graphify update .`를 실행했다.

## 6. 남은 작업 / 보류 사항

- 이번 후속 변경은 관련 시험과 Chrome MSW 데모를 검증했다. 전체 Vitest는 앞선 드롭다운 변경에서 771개가 통과했다.
