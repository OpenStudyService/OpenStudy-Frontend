# 2026-11-13 추천 질문에 "지난 달 지점별 매출" 추가

## 1. 배경 / 문제

- 백엔드에서 등록 분석이 질문의 기간을 읽도록 고쳤다(OpenStudy-Backend `fix/registered-analysis-question-period`). 사용자가 "이번 달"과 "지난 달 지점별 매출을 비교해줘"의 기간이 정상으로 설정되는 것을 브라우저에서 확인했다.
- 사용자 요청: 추천 질문에서 "지난 달 지점별 매출을 비교해줘"를 "이번 달 지점별 매출을 비교해줘" 버튼 바로 옆에 둔다.

## 2. 검토한 선택지

- `POC_QUESTIONS`에 항목을 더한다: 이 목록은 등록 분석마다 하나씩이다. 결과 제목(`parseAiResult`)과 적용 조건의 분석 이름(`analysisName`)이 분석 ID로 이 목록을 찾으므로, 같은 분석 ID가 둘이 되면 안 된다.
- 추천 질문 목록(`SUGGESTED_QUESTIONS`)을 따로 둔다(선택). `POC_QUESTIONS`에서 만들고, 지점별 매출 바로 뒤에 지난 달 질문을 넣는다.

## 3. 결정 및 이유

- 두 버튼을 구분할 수 있도록 추천 질문 칩 이름을 "이번 달 지점별 매출 비교"와 "지난 달 지점별 매출 비교"로 붙였다. 결과 제목·분석 이름("지점별 매출 비교")은 그대로다.
- 새 질문은 같은 등록 분석(POC-001)을 묻고, 기간은 서버가 질문에서 읽는다. 매출 조회 권한 조건도 같다.

## 4. 구현 내용

- `domainlens.ts`: `SUGGESTED_QUESTIONS`(칩 이름 `label` 포함)
- `Ai.tsx`: 처음 화면의 질문 카드와 "추천 질문" 칩 목록이 `SUGGESTED_QUESTIONS`를 쓴다.

## 5. 검증 결과

- `Ai.test.tsx`(2개 추가)
  - 추천 질문 칩에서 "지난 달 지점별 매출 비교"가 "이번 달 지점별 매출 비교" 바로 다음에 있고, 누르면 "지난 달 지점별 매출을 비교해줘"를 묻는다.
  - 처음 화면의 질문 카드에서도 두 질문이 나란히 있다.
- `npm run typecheck`, `npm run lint` 통과
- `npm test`: 837개 통과
- `npm run build` 통과
- 브라우저 확인(기간 수정 백엔드, 확인용 DB, 이 브랜치를 5182 포트로 실행)
  - 처음 화면 카드와 추천 질문 칩 모두 두 질문이 나란히 보인다.
  - "지난 달" 칩을 누르면 기간 2026-10-01 ~ 2026-10-31, 제목 "2026년 10월 전체 순매출 요약", 지점별 11,000원 / 25,000원(DB 합계와 같음)이다.

## 6. 남은 작업 / 보류 사항

- 이 질문이 다른 결과를 내려면 백엔드 기간 수정(`fix/registered-analysis-question-period`)이 병합돼야 한다. 병합 전 백엔드에서는 "이번 달"과 같은 결과가 나온다.
- 적용 조건의 기간이 "변경한 기간"으로 표시된다. 질문에서 지정한 기간을 따로 표시하려면 백엔드 API 계약 변경이 필요하다.
