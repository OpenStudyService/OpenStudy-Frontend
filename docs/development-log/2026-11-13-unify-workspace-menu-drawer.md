# 좁은 화면의 운영 메뉴 위치와 버튼 통일

홈·채팅에만 왼쪽 배치를 적용해 업무 등 다른 화면의 운영 메뉴가 오른쪽에서 열렸다. 공통 운영 메뉴의 위치를 태블릿에서는 레일 옆, 모바일에서는 화면 왼쪽으로 통일했다.

상단 메뉴 버튼과 메뉴 내부 닫기 버튼은 공통 `Button`의 `primary` 스타일을 사용한다. 운영 메뉴에서 닫기 버튼의 스타일을 지정할 수 있도록 `Panel`에 옵션을 추가했다.

TypeScript, ESLint, 전체 Vitest 814개, 운영·데모 빌드와 산출물 검사가 통과했다. Chrome 데모의 관련 테스트 5개에서 1099px·390px 업무 및 설정 메뉴의 왼쪽 위치, 두 버튼의 배경색 일치, 닫기 후 포커스 복귀를 확인했다. 프론트엔드 Graphify를 갱신했다.
