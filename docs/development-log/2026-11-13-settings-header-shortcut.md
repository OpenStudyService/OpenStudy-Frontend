# 헤더에 개인 설정 바로가기 추가

## 1. 배경 / 문제

개인 설정이 사용자 드롭다운 안에만 있어 리뷰 중 설정을 찾기 어렵다는 의견이 나왔다. [PR #119](https://github.com/OpenStudyService/OpenStudy-Frontend/pull/119)

## 2. 검토한 선택지

기존 데스크톱 빠른 탐색과 모바일 하단에 각각 바로가기를 복원하는 방식과 두 화면의 공통 헤더에 바로가기를 두는 방식을 비교했다.

## 3. 결정 및 이유

화면 크기에 관계없이 같은 위치에서 찾을 수 있도록 헤더 사용자 메뉴 옆에 톱니바퀴와 **설정** 문구를 표시한다. 사용자 드롭다운에도 개인 설정을 제공한다.

## 4. 구현 내용

설정 바로가기는 현재 지점의 개인 설정 주소로 연결한다. 개인 설정을 보고 있을 때 버튼의 활성 스타일과 현재 페이지 속성을 표시한다.

## 5. 검증 결과

Chrome MSW에서 OWNER·지점 관리자·일반 직원으로 데스크톱과 모바일 헤더의 바로가기 노출, 클릭 이동, 활성 상태를 확인했다. 타입 검사·린트와 관련 Vitest도 통과했다.

## 6. 남은 작업 / 보류 사항

이번 후속 커밋은 헤더 진입점의 영향 범위만 재검증했다.
