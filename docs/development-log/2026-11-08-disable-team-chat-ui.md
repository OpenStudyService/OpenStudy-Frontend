# 2026-11-08 · 팀 채팅 비활성화와 AI 채팅 진입점 통합

## 배경 / 문제

[Frontend #70](https://github.com/OpenStudyService/OpenStudy-Frontend/issues/70)에 따라 서비스에서 제외된 팀 채팅을 화면에서 비활성화한다. [Backend #179](https://github.com/OpenStudyService/OpenStudy-Backend/pull/179) 이후에는 인증된 요청도 기본 설정에서 채널 API의 404 응답을 받는다. [Frontend #81](https://github.com/OpenStudyService/OpenStudy-Frontend/pull/81)의 홈 요약은 이미 메시지 대신 AI 채팅 바로가기를 제공한다.

## 검토한 선택지와 결정

채팅 기능을 설정 상수로 제어하는 방법과 앱의 연결을 제거하는 방법을 검토했다. 팀 채팅을 제공하는 빌드가 필요하지 않아 라우트와 메뉴에서 연결을 제거했다. 채팅 기능의 구현과 내부 테스트는 보존했다. 기존 링크를 계속 사용할 수 있도록 두 레거시 주소는 동일 지점의 채팅 탭 주소로 기록을 교체한다.

## 구현 내용

- 데스크톱과 모바일 채팅 메뉴 및 홈 바로가기에서 기존 AI 화면의 지점별 AI 조회 권한을 사용한다. 별도의 업무 AI 메뉴를 제거했다.
- 설정의 채널 관리와 업무 상세의 업무 카드 공유 연결을 제거했다. 앱 초기화는 채널이 없는 기본 조회 데이터를 사용한다. 로그아웃에서 기존 채팅 세션 정리는 메모리만 비우며 채널 API를 호출하지 않는다. [Frontend #80](https://github.com/OpenStudyService/OpenStudy-Frontend/pull/80) 이후 공통 SSE와 채팅 읽음 이벤트 구독이 남아 있지 않음을 확인했다.
- 데모의 채널 및 레거시 팀 채팅 요청은 404를 반환한다. 비활성화된 기능에 의존하는 라이브 팀 채팅 시나리오에는 중단 사유를 표시했다.
- 백엔드 원격 main의 92196dc 커밋에서 임시 파일로 OpenAPI를 가져와 Foundation 타입을 생성했다. 채널 operation 15개 모두 계약에서 기본 비활성화 및 폐기 예정으로 표시되고 생성 타입에 `@deprecated`가 반영됐다.

## 검증 결과

- TypeScript, ESLint, Vitest 620개, 라이브·데모 빌드와 양쪽 빌드 검사 통과.
- 데모 빌드에서 Playwright 14개 통과. 레일과 홈에서 AI 채팅 열기, 두 레거시 주소의 지점 유지와 뒤로 가기, 권한이 없는 직원의 진입점 비노출과 직접 접근 거부를 확인했다. 설정과 업무 공유의 레거시 주소에서도 채널 기능이 표시되지 않았고 로그인부터 로그아웃까지 채널 요청은 0건이었다. 데모 채널 요청의 404도 확인했다.
- 라이브·데모 배포 빌드 브라우저 검사 5개 통과.
- graphify 증분 갱신과 Git diff 공백 검사 완료.

## 남은 작업 / 보류 사항

- 로컬 백엔드를 연결한 `npm run dev:live` 세션과 배포 환경의 네트워크 검증은 미실행이다.
- 개발 서버에서 일부 브라우저 테스트가 초기 로드 중 시간 초과를 기록해 동일 검증을 데모 빌드에서 재실행했다.
- 기존 AI 응답 확장 시나리오의 질문 입력 라벨은 기준 main의 AI 화면과도 일치하지 않는다. 해당 테스트는 입력 단계에서 시간 초과됐으며 데모 빌드 재실행 집계에서 제외했다.
- 라이브·데모 빌드에서 Vite의 500 kB 번들 크기 경고가 발생했다.
