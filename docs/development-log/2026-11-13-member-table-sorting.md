# 2026-11-13 회원 목록 열 제목 정렬

## 배경 및 결정

회원 목록의 정렬 기준과 방향을 필터 바의 두 메뉴에서 선택해야 했다. 정렬을 해당 열 제목에서 바로 조작할 수 있도록 옮겼다. 검색 결과 전체에 같은 순서를 적용할 수 있도록 기존 목록 API가 지원하는 회원 이름과 등록일을 사용했다.

## 구현

- 정렬할 수 있는 열에는 버튼과 화살표를 표시하고, 활성 열에는 `aria-sort`로 현재 방향을 전달한다.
- 같은 제목을 다시 누르면 방향을 뒤집는다. 회원 이름을 처음 선택하면 오름차순, 등록일을 처음 선택하면 최신순이다.
- 검색 조건과 페이지 크기를 유지한 채 첫 페이지로 이동한다. 정렬 기준과 방향은 URL에 기록해 새로고침 후에도 복원한다.

## 검증

- 전체 Vitest 806건, 린트, 타입 검사를 포함한 운영용 빌드 및 산출물 검사가 통과했다.
- 격리된 모의 서버에서 회원 관리 Playwright 4건이 통과했다. 제목 버튼으로 설정한 정렬이 새로고침 후에도 복원되는지 확인했다.
- 운영 환경 확인은 수행하지 않았다. 작업공간 코드 그래프를 갱신했다.
