# 2026-11-12 · 좌석 등록 버튼을 필터 바 오른쪽에 정렬

공간 관리의 좌석 현황에서도 [공통 등록 버튼 배치](2026-11-12-align-create-buttons-with-filters.md)를 적용했다. 기존 필터 바의 마지막 버튼에 왼쪽 자동 여백을 주어 데스크톱과 모바일에서 오른쪽에 정렬했다. 지점 선택과 좌석 등록 권한 조건, 등록 패널 연결은 유지했다.

타입 검사, 린트, 관련 Vitest 41개가 통과했다. Chrome과 Mock API를 사용한 Playwright 검증에서 좌석 등록 버튼의 데스크톱·모바일 위치, 등록 패널 열기·닫기, 좌석 상태 필터 유지를 확인했다.
