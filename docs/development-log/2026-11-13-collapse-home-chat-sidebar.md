# 홈·채팅 메뉴 사이드바 기본 접기

## 배경과 결정

홈과 채팅에서 운영 메뉴 열이 본문 너비를 차지했다. 두 화면은 내비게이션 레일 옆까지 본문을 넓히고, 사용자가 선택한 상단 메뉴 버튼으로 지점 선택과 운영 메뉴를 열 수 있게 했다. 기존 반응형 메뉴 패널을 재사용해 화면 크기에 따라 같은 메뉴와 권한 필터를 제공한다.

## 구현

- 공통 레이아웃에서 홈·채팅의 고정 메뉴 열을 제거하고 화면 또는 지점이 바뀌면 패널을 닫는다. 업무·설정 등 다른 데스크톱 화면은 고정 메뉴를 사용한다.
- 고정 메뉴와 패널의 지점 선택 입력에 각각 다른 ID를 부여해 태블릿과 모바일에서 입력 레이블이 패널의 지점 선택에 연결되도록 했다.
- 홈의 기존 지점 선택과 재조회 테스트는 메뉴를 연 뒤 조작하도록 갱신했다.

## 검증

- TypeScript, ESLint, 관련 Vitest 22개, 전체 Vitest 814개, 운영 빌드와 산출물 검사 통과.
- Mock Chrome 1100px·1099px·390px에서 홈·채팅 직접 진입, 빠른 탐색, 본문 폭, 메뉴 열기, Escape와 포커스 복귀, 지점 전환과 뒤로가기, 업무·설정 메뉴 배치를 확인했다.
- Chrome의 기존 반응형·접근성·지점 전환·메뉴 재조회 회귀 8개도 통과했다. 1440px 반응형 검사는 첫 실행에서 로그인 로딩 시간이 초과되어 단독 재실행으로 통과를 확인했다.
- 워크스페이스와 프론트엔드의 Graphify AST 그래프를 갱신했다.

## 남은 작업

실제 운영 환경과 물리 모바일 기기는 미검증이다.
