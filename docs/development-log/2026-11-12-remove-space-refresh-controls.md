# 2026-11-12 예약·공간 관리의 새로고침 버튼 제거

## 배경과 결정

공통 업무 화면 상단의 새로고침은 PR #97에서 제거했지만, 스터디룸 예약과 공간 관리의 사물함·스터디룸·좌석 현황에는 화면별 버튼이 남아 있었다. 각 화면은 현재 메뉴를 다시 클릭하면 활성 조회를 갱신하므로 같은 역할의 버튼을 제거한다.

## 구현

- 스터디룸 예약, 사물함, 스터디룸 관리, 좌석 현황의 목록 새로고침 버튼을 제거했다.
- 현재 메뉴를 다시 누르면 활성 탭과 조회 조건이 유지된다. 조회 오류의 다시 시도와 입력 중 필요한 조회는 기존 동작을 사용한다.

## 검증

- 전체 Vitest 757개, ESLint, 타입 검사와 운영 모드 빌드를 통과했다.
- Chrome 모의 API 테스트 3개를 통과했다. 네 화면에서 목록 새로고침 버튼이 사라지고 메뉴 재클릭으로 같은 URL의 데이터를 다시 읽는 것을 확인했다. 사물함은 목록과 점유 현황이 함께 갱신됐다.
- 운영 서버에 연결한 브라우저 검증은 수행하지 않았다.
