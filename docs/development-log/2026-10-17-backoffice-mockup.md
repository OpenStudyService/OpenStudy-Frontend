# 2026-10-17 · OpenStudy 백오피스 HTML 목업

## 배경 / 문제

실제 프론트엔드 구현과 PRD·Task 전달에 앞서, 스터디카페 사장님과 직원이 사용할 백오피스의 디자인과 기본 흐름을 검토해야 했다. 참고 자료는 `docs/mockup/`의 OpenOffice HTML 3개였으며 공유오피스용 기업·택배 관리와 별도 채팅 화면을 포함하고 있었다.

## 검토한 선택지

- 단일 고정 색상 대신 세 테마를 선택해 비교하도록 사용자가 요청했다.
- 결과물 형태로 정적 시안, React 프로토타입, 클릭 가능한 HTML을 검토했고 HTML을 선택했다.
- 참고 메뉴 유지 또는 협업 핵심 화면만 먼저 만드는 방식과 비교해, 스터디카페 운영용으로 메뉴 전체를 재구성하기로 했다.
- 역할과 기기는 공통 화면 하나·PC 전용 대신 사장님/직원 전환과 PC 중심 모바일 대응을 선택했다.

## 결정 및 이유

- `docs/mockup/openstudy/`에 별도 결과물을 만들고 기존 참고 파일을 보존했다.
- 빌드 없는 HTML/CSS/JavaScript로 구현했다. 프레임워크와 API 계약은 PRD를 받은 이후 결정하며, 현재는 파일을 직접 열어 검토할 수 있도록 했다.
- 앱 레일·보조 탐색·본문·상세 패널을 공통으로 사용해 업무와 채팅 사이의 맥락을 유지했다.
- 포레스트·네이비·샌드 테마를 CSS 변수로 정의했다. 테마만 브라우저에 저장하며 그 외 데이터는 메모리에서만 유지한다.
- 업무·홈·채팅 카드는 동일한 업무 상태를 참조한다. 채팅에 공유된 카드가 별도 상태 복사본이 되지 않도록 했다.
- 현재 프론트엔드 폴더와 상위 작업 폴더에는 Git 메타데이터가 없어 작업 브랜치를 생성할 수 없었다. 저장소를 임의로 초기화하지 않고 지정된 폴더에 결과물만 작성했다.

## 구현 내용

- 로그인, 홈, 업무, 채팅, 회원·이용권, 예약, 좌석·사물함, 시설·점검, 고객 문의, 공지, 근무·근태, 직원 관리, 설정의 13개 화면.
- 업무 등록·담당자 지정·상태 변경·체크리스트·채팅 공유·스레드 보고와 홈 집계/최근 공유 연결.
- 채널·DM, 메모리 내 메시지·답글 전송, 입력 중인 초안 유지, 업무 카드 첨부.
- 검색·필터·빈 목록, 예약 캘린더/목록, 구역별 대표 좌석, 상세 패널, 공지 작성/고정, 문의 답변과 시설 상태 변경.
- 사장님/직원 역할 미리보기, 직원의 관리 메뉴 및 지점 설정 숨김, 직원 관리 주소의 홈 전환.
- 모바일 하단 탐색과 메뉴 서랍, 본문 영역별 스크롤, 상세창/스레드, 키보드 포커스 순환·복원 및 모션 감소 대응.
- 한국어 실행 안내, 시나리오, 상태 초기화 규칙, 기능별 데모 범위와 기본 상태 미리보기.

## 검증 결과

- `node --check app.js`, `node --check data.js` 통과.
- 시스템 Chrome과 Playwright로 실제 `file://` 경로를 열어 **189개 검사 통과**, 브라우저 콘솔 오류 **0개**.
- 1440×1000, 1024×1000, 390×844에서 모든 업무 화면의 본문 가시성, 페이지 전체 가로 넘침, 채팅 입력창과 업무 등록 하단 버튼 위치 확인.
- 업무 생성 → 채팅 공유 → 직원 전환 → 스레드 보고 → 업무 완료 → 목록·홈·카드 상태 반영 검증.
- 로그인 오류, 테마 전환/재접속 유지, 비밀번호 미저장, 새로고침 시 업무 초기화, 역할별 메뉴·직접 주소 제한 확인.
- 검색·날짜/상태 필터·빈 목록, 예약 상세, 좌석 상태, 시설·문의 처리, 공지 작성/고정, 근태 시뮬레이션 확인.
- 주요 테마 글자/배경 조합의 WCAG AA 4.5:1 대비 계산, 버튼·입력 레이블, 키보드 상세창 순환·Esc 닫기, 상태 변경 중 포커스/작성 내용 유지 확인.
- 데스크톱 로그인·홈, 모바일 홈·채팅·좌석·등록 폼, 태블릿 설정 화면의 캡처를 시각적으로 검토했다.
- 검증 중 오늘의 업무 집계 기준, 다이얼로그 close 이벤트 경합, 검색 입력 blur의 중복 렌더, 모바일 동일 메뉴 재선택 시 닫기, 네이비 보조색 대비와 상세창 포커스를 보완했다.

검증 스크립트는 `docs/mockup/openstudy/qa.cjs`에 있으며, 상세 결과와 캡처는 `qa-artifacts/`에 생성한다. 로컬 HTTP 접속이 실행 환경에서 제한되어 서버 방식 대신 파일 직접 실행으로 검증했고 임시 서버는 종료했다.

## 남은 작업 / 보류 사항

- PRD·Task 수령 후 메뉴, 사용자/역할 체계, 권한, 지점 범위, 실제 업무 처리 규칙 확정.
- 실제 인증, 서버 API, 결제/정산, 실시간 통신, 파일 업로드, 초대/알림, 예약/근태 처리 연동.
- 실제 모바일 기기의 가상 키보드, 다른 브라우저 엔진, 스크린리더 음성 출력 검증.
- 선택한 디자인을 실제 프론트엔드 컴포넌트와 서비스 데이터 구조로 전환.

이 목업의 가상 데이터·역할 제한·화면 동작을 실제 서비스의 보안 및 업무 정책으로 간주하지 않는다.
