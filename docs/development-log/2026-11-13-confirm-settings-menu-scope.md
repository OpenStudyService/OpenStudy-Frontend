# 설정 메뉴 분류안 사용자 확정

## 1. 배경 / 문제

[PR #115](https://github.com/OpenStudyService/OpenStudy-Frontend/pull/115)에서 조사 결과와 분류안을 정리했다. PR 병합 후 사용자가 추천안대로 진행하기로 했다. [#108](https://github.com/OpenStudyService/OpenStudy-Frontend/issues/108)

## 2. 검토한 선택지

추천안 A와 변경 이력을 지점 관리 안에 두는 B안, 데스크톱 설정 아이콘을 유지하는 C안은 [최초 조사 기록](2026-11-13-settings-menu-scope.md)과 [설계 문서](../design/settings-menu-scope.md)에 남아 있다.

## 3. 결정 및 이유

사용자가 추천안 A를 확정했다. 개인 설정 진입은 사용자 메뉴로 모으고, 지점 정보·휴무일 조회 권한을 유지하며, 스터디룸은 기존 공간 관리 탭으로 통합한다. 지점 외 대상도 다루는 변경 이력은 OWNER 전용 운영 관리에 배치한다. 알림 안내 카드와 MOCK 도구 처리, 기존 주소의 호환 동작도 추천안대로 적용한다.

## 4. 구현 내용

- 설계 문서에 확정 상태와 배치·주소 동작을 반영했다. 화면 변경은 [#111](https://github.com/OpenStudyService/OpenStudy-Frontend/issues/111)에서 진행한다.
- #111의 현재 인수 조건과 비교했다. 사용자 메뉴 단일 진입, 알림 안내 제거 및 MOCK 도구 이동, 일반 직원의 지점·휴무일 조회, 기본 설정 주소 유지와 운영 링크별 검색·상세 보존을 구체화할 필요가 있다.

## 5. 검증 결과

- 확정 문서와 #111 본문의 작업 범위·인수 조건을 대조했다. 화면 검증 결과는 [최초 조사 기록](2026-11-13-settings-menu-scope.md#5-검증-결과)에 있다.
- 확정 상태만 문서에 반영했으므로 프로젝트 테스트·빌드와 MSW 데모를 다시 실행하지 않았다.

## 6. 남은 작업 / 보류 사항

- #111 본문 보완안을 사용자에게 제안한다. 본문 수정은 사용자 확인 뒤 진행한다.
- #111에서 확정안 구현과 역할별 메뉴·기존 링크 동작을 검증한다.
