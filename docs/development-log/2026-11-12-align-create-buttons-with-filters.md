# 2026-11-12 · 등록 버튼을 검색·필터 바에 배치

## 배경과 결정

메뉴를 바꿀 때마다 등록 버튼을 제목 영역이나 탭 본문에서 찾아야 했다. 회원 관리, 스터디룸 예약, 공간 관리의 스터디룸 탭, 시설 관리, 고객 문의, 공지사항에서는 목록 조건을 설정하는 곳에서 등록도 시작할 수 있도록 기존 검색·필터 바 오른쪽에 버튼을 배치했다.

## 구현

- 기존 필터 바의 줄바꿈을 활용했다. 좁은 화면에서 버튼이 다음 줄로 내려가도 오른쪽에 정렬된다.
- 등록 버튼의 문구·스타일·권한 조건·패널 연결을 유지했다. 중복 고객 확인과 화면별 새로고침은 기존 위치에 둔다.

## 검증

- 타입 검사, 린트, live 프로덕션 빌드 및 산출물 검사 통과.
- 전체 Vitest 86개 파일, 753개 테스트가 통과했다. 첫 실행에서는 AI 테스트 1개가 시간 제한을 넘겨 작업자 수를 4개로 줄여 전체를 다시 실행했다.
- Chrome과 Mock API로 여섯 화면의 1440px·390px 오른쪽 정렬, 패널 열기·닫기, 조회 조건 유지와 읽기 전용 직원의 회원 등록 버튼 미표시를 확인했다. 로컬 로그인 초기 로딩 시간 제한을 늘려 관련 Playwright 시나리오 2개를 통과했다.
