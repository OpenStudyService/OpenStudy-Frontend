# 2026-11-13 회원 목록 전체 열 정렬

## 배경 및 결정

기존에는 회원 이름과 등록일 제목으로만 정렬할 수 있었다. 회원번호, 연락처, 상태, 등록 지점에도 같은 동작을 적용하고, 필터를 적용한 전체 결과의 순서를 유지하도록 기존 목록 API를 확장해 사용했다.

## 구현

- 여섯 열 모두 제목 버튼과 현재 방향을 표시한다. 같은 제목을 다시 누르면 방향이 바뀐다.
- 새로 선택한 등록일은 최신순으로, 다른 열은 오름차순으로 시작한다. 등록 지점은 지점 이름으로 정렬한다.
- 기존 검색 조건과 페이지 크기를 유지하고 정렬을 바꾸면 첫 페이지로 이동한다. 정렬 조건은 URL에 기록한다.
- 데모 회원 API에도 같은 정렬 기준을 적용했다. 실제 환경에서는 확장된 백엔드 목록 API가 필요하다.

## 검증

제목 클릭으로 새 정렬 기준과 양방향이 API에 전달되는지 테스트했다. 전체 Vitest 811건, 린트, 타입 검사를 포함한 운영용 빌드가 통과했다.
