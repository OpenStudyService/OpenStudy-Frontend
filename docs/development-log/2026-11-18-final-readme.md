# 2026-11-18 프로젝트 마무리 README 정리

## 1. 배경 / 문제

- 프로젝트 마무리를 위해 README를 정리했다.
- 기존 README는 "현재 완료 범위는 프론트엔드와 MSW 기반 통합 시연"이라고 설명했다. 이후 고객·결제·좌석·업무·채팅·근태 등은 실제 Backend·MySQL 연결 브라우저 검증(`docs/testing/*-live.md`)까지 진행되어 설명이 실제 상태와 맞지 않았다.
- 소개·화면 이미지가 없어 처음 보는 사람이 서비스를 파악하기 어려웠다.

## 2. 검토한 선택지

| 선택지 | 판단 |
|---|---|
| 개발자 인수인계형 | 기존 README가 이 형태였다. 실행 명령 표가 길고 소개가 부족했다 |
| 포트폴리오·발표형 | 사용자가 선택. 화면·기능·설계 포인트를 앞에 두고, 실행·검증 정보는 간결하게 유지 |

## 3. 결정 및 이유

- 상단에 화면 캡처 5장과 기술 스택·주요 화면·설계 포인트를 배치했다.
- 실행 명령은 핵심 5개만 표로 두고, 기능별 live/mock 명령은 `<details>`로 접었다.
- 검증 범위는 "실서버 검증 완료 기능"과 "남은 항목(#32, #35, #36)"을 나누어 적었다. MSW 결과를 실서버 검증처럼 쓰지 않았다.
- 상위 폴더(`../docs/api`)를 가리켜 GitHub에서 깨지던 링크를 제거했다.

## 4. 구현 내용

- `README.md` 재작성.
- `docs/images/readme/`에 화면 캡처 추가: 홈, 좌석 배치도, AI 분석 결과, 업무 관리(1440×900), 모바일 홈(390×844). `npm run dev` 데모 모드에서 Playwright로 캡처했다.

## 5. 검증 결과

- README의 상대 링크·이미지 경로가 저장소에 존재하는지 스크립트로 확인했다.
- README에 적은 npm 명령이 `package.json` scripts에 있는지 확인했다.
- 코드 변경이 없어 typecheck·lint·테스트는 실행하지 않았다.

## 6. 남은 작업 / 보류 사항

- 검증 범위 절은 2026-11-18 기준이다. #32·#35·#36이 닫히면 갱신이 필요하다.
- 캡처는 데모 데이터 화면이다. 실서버 화면 캡처는 하지 않았다.
