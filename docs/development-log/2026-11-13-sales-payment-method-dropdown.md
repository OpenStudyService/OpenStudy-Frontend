# 2026-11-13 · 매출 조회 결제 수단 드롭다운

## 1. 배경 / 문제

상품 유형과 환불 처리 지점을 체크박스 드롭다운으로 바꾼 뒤 결제 수단은 기본 다중 선택 목록으로 남아 조작 방식이 달랐다.

## 2. 결정 및 이유

기존 매출 필터 드롭다운을 결제 수단에도 사용해 세 다중 선택 조건의 조작 방식과 선택 표시를 맞췄다.

## 3. 구현 내용

현금·카드·계좌이체·기타를 체크박스 드롭다운으로 표시한다. 기존 URL과 API의 `methods` 값을 사용한다.

## 4. 검증 결과

- 관련 Vitest 3개 파일·44개, 타입 검사, 린트, MSW 빌드 통과. 카드가 선택된 상태에서 현금을 추가하면 두 값이 원장 조회 요청에 포함되는 것을 확인했다.
- Chrome MSW 데모 390·1024·1440px에서 열기, 선택·해제, Esc 닫기를 확인했다.
- `graphify update .`를 실행했다.

## 5. 남은 작업 / 보류 사항

- 전체 Vitest는 직전 드롭다운 변경에서 771개가 통과했다. 이번 후속 변경은 관련 시험과 브라우저를 검증했다.
