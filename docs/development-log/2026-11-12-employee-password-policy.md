# 2026-11-12 직원 비밀번호 설정 화면 검증 통일

## 배경과 결정

신규 초대의 최소 길이 계산 방식이 서버와 달랐다. 새 비밀번호를 설정하는 초대 수락, 변경, 재설정 화면과 모의 API에 공통 검증을 적용한다. 입력 전에 조합 조건을 안내하고 실패 시 입력란에서 이유를 확인할 수 있게 한다.

## 구현

- 영문, 숫자, ASCII 특수문자를 각각 하나 이상 포함하고 8자 이상인지 확인한다. 길이는 유니코드 코드 포인트로 세고 UTF-8 72바이트 상한을 적용한다.
- 신규 초대에서는 정책과 비밀번호 확인을 모두 통과해야 수락 요청을 전송한다. 기존 로그인은 현재 비밀번호 검증을 적용한다.
- 서버 OpenAPI에서 프런트엔드 계약을 재생성했다.

## 검증

- 전체 Vitest 757개가 통과했다. 첫 병렬 실행에서 AI 계약 테스트 하나가 5초 제한을 넘겼고, 작업자 4개로 다시 실행했을 때 통과했다.
- ESLint, 타입 검사와 운영 모드 빌드를 통과했다.
- Chrome 모의 API 초대 시나리오 2개를 통과했다. 특수문자 누락과 확인값 불일치 안내를 확인한 후 정상 비밀번호로 초대를 수락했다.
