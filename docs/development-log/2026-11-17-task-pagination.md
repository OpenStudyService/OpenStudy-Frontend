# 2026-11-17 · 업무 관리 페이지네이션

## 배경 / 문제

업무 목록은 이전·다음 버튼으로 한 페이지씩 이동했다. 결제 관리의 고객 검색 모달처럼 페이지 번호를 눌러 원하는 페이지로 이동할 수 있도록 변경했다.

## 결정 및 이유

고객 검색 모달의 공용 `Pagination`을 재사용했다. 두 화면에서 10개 단위 페이지 번호, 현재 페이지 강조, 이전·다음 버튼이 같은 방식으로 동작한다.

## 구현 내용

- 업무 목록 하단 중앙에 전체 건수와 페이지 이동 버튼을 배치했다. 결과가 한 페이지 이내이면 전체 건수를 표시한다.
- API 응답의 전체 건수와 페이지 크기로 페이지 수를 계산한다. 페이지 이동은 기존 URL에서 `page` 값만 갱신해 검색·필터·정렬 조건을 유지한다.

## 검증 결과

- `npm run typecheck`, `npm run lint`, `git diff --check` 통과.
- 업무 관리, 공용 페이지네이션, 결제 관리 관련 Vitest 6개 파일, 67개 테스트 통과. 번호로 직접 이동할 때 API 응답의 페이지 크기를 사용하는지, URL과 조회 조건을 유지하는지, 조회 오류 상태에서 페이지 이동이 표시되지 않는지 확인했다.
- Chrome으로 Mock 화면 확인을 시도했으나 실행 환경에서 로컬 서버 접속을 차단했다. 실제 화면과 운영 API는 확인하지 않았으며, 전체 테스트와 빌드는 실행하지 않았다.
