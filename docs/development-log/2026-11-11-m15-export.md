# 2026-11-11 매출·AI 분석 결과 내보내기

## 1. 배경 / 문제

- Frontend #47의 FR-AGG-16은 매출·집계와 자연어 분석 결과의 CSV 다운로드, 차트 PNG 저장, 내보내기 전 잘림 안내를 요구한다.
- Backend `origin/main`의 `6e07292`에서 CSV 계약과 구현을 확인했다. 서버가 조회 조건과 현재 권한으로 CSV를 생성하고 감사 기록을 남긴다. 이전 반출 승인 경로는 제거됐다.
- Frontend `origin/main`에는 #46의 결과 재사용이 PR #95로 병합돼 있었다. 그 상태를 기준으로 별도 worktree에서 작업했다.

## 2. 검토한 선택지

- CSV는 기존 API 클라이언트의 인증, 세션 취소, JSON 오류 처리를 재사용하고 응답 본문만 Blob으로 읽도록 했다. 화면의 JSON 응답으로 파일을 만들면 서버가 수행하는 권한 재검증과 감사 기록을 이용할 수 없다.
- PNG는 Recharts가 실제로 그린 SVG를 복제해 Canvas에 합성한다. 원본 SVG를 사용하면 값, 정렬, 축과 차트 종류를 별도 로직으로 다시 계산할 필요가 없다.

## 3. 결정 및 이유

- 사용자와 합의한 대로 보고서와 AI 데이터셋 제목 옆에 **CSV 다운로드**, Recharts 차트 바로 위에 **PNG 저장**을 배치했다. 버튼은 좁은 화면에서 줄바꿈한다.
- PNG는 화면 차트의 CSS 픽셀을 기준으로 2배 해상도로 저장한다. 흰 배경과 24 CSS px 여백을 두고 제목·조회 조건·단위·기준 시각을 차트 위에 표시한다. 긴 문구는 줄바꿈하고 정보 영역을 확장한다. 글자와 여백에도 같은 배율을 적용한다.
- 사용자와 합의한 PNG 범위는 Recharts 차트다. HTML/CSS로 그리는 AI 순위 막대와 혼잡도 히트맵은 후속 작업으로 기록한다.
- 원장과 상품 순위는 `meta.total`, 매출 요약·지점 비교·추세는 `aggregation.rowCount`, 이용권 사용은 지점별 판매 지점 상세 행의 합으로 1,000행 초과 여부를 판단한다. 이용권 판매량 CSV는 한 행이다. AI는 데이터셋의 `totalElements`와 결과의 `truncation.isTruncated`를 사용한다. 전체 수와 잘림 신호를 알 수 없는 결과에서는 사전 안내를 표시할 근거가 없으며, CSV 본문의 머리말에서 실제 행 수와 잘림 여부를 확인할 수 있다.

## 4. 구현 내용

- 매출·집계 7개 보고서의 CSV 요청은 화면과 동일한 필터 및 보고서별 정렬·집계 옵션을 전송한다. 원장과 상품 순위의 화면 페이지 조건은 CSV 요청에서 제외했다.
- 본인 대화·최근 질의에서 완료된 AI 실행의 각 데이터셋을 `executionId`와 `datasetId`로 내려받는다. 기존 화면 접근 제어와 서버의 권한 오류 처리를 재사용한다.
- 서버의 UTF-8 파일 이름을 해석하고, 헤더를 읽을 수 없는 경우 보고서 이름과 서울 시각으로 이름을 생성한다. 공통 버튼이 파일 준비 중 중복 클릭을 막고 API 오류 코드와 메시지를 보여 준다.
- MSW에서 매출·AI CSV, BOM·CRLF·머리말, 1,000행 상한, 권한·보고서 이름·빈도 제한 오류를 재현했다. 기존 `/api/ai/approvals` 목업은 제거했다.
- Backend `origin/main`에서 OpenAPI를 임시 파일로 꺼내 `foundation.generated.ts`를 다시 생성하고 Prettier를 실행했다. Git 기준 생성 내용이 기존 파일과 일치했다.

## 5. 검증 결과

- `npm run typecheck`, `npm run lint`, 관련 단위 테스트 및 MSW 계약 테스트 66개 파일 606건 통과.
- `npm test` 전체 단위 테스트 86개 파일 753건 통과.
- `npm run build`와 `check:build:live` 통과. Vite의 500 kB 초과 청크 경고가 있었다.
- 단위 테스트에서 8개 화면 경로의 CSV 쿼리 일치와 페이지 필드 제외, 파일 이름과 대체 이름, 1,000행 사전 안내 및 CSV 잘림, 중복 클릭, AI 데이터셋 선택·권한·오류를 확인했다. PNG의 원본 SVG 도형 및 한글 레이블 유지, 2배 해상도, 메타데이터 줄바꿈과 차트 배치를 확인했다.
- 새 worktree에 `graphify-out`이 없어 worktree 내 조회와 갱신을 생략했다. 초기 위치 확인에는 상위 워크스페이스의 그래프를 사용했다.

## 6. 남은 작업 / 보류 사항

- **마일스톤 검증으로 미룸(미실행)**. live 빌드의 실제 API CSV 다운로드와 화면 수치 대조, 실제 브라우저에서 저장한 PNG의 한글과 차트 수치 확인, 통합 테스트 및 Playwright E2E.
- Backend `origin/main`의 다시 연 대화 성공 응답은 실행 ID와 적용 조건을 반환하지 않는다. 이 응답의 AI 카드는 CSV 대상 실행과 PNG에 필요한 조건을 확인할 수 없다. 실행 ID와 조건을 제공하는 백엔드 응답이 필요하다.
- AI 순위 막대와 혼잡도 히트맵의 PNG 저장은 후속 범위다.
