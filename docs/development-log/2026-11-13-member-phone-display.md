# 2026-11-13 회원 연락처 표시 형식

## 배경 및 결정

회원 목록과 상세 패널은 서버에서 받은 숫자 문자열을 그대로 표시해 연락처를 읽기 어려웠다. 화면에 값을 그리는 시점에 공통 포맷 함수를 적용하면 저장과 검색에 쓰는 정규화된 연락처를 유지하면서 두 화면에서 같은 형식으로 표시할 수 있다.

## 구현

- 회원 목록과 상세 패널에 `010-1234-5678` 형태의 표시를 적용했다. `02` 지역번호와 `050x` 번호는 각 접두사 길이에 맞춰 구분한다.
- 이미 구분 기호가 있거나 지원하는 패턴과 일치하지 않는 값은 원문을 표시한다.

## 검증

- 회원 목록과 상세 패널의 하이픈 표시를 기존 화면 테스트에 추가했다. 전체 Vitest 805건이 통과했다.
- 휴대전화, 서울 및 기타 지역번호, `050x`, 원문 유지 등 포맷 함수의 7개 입력을 별도로 확인했다.
- `npm run typecheck`, `npm run lint`, `npm run build`가 통과했다. 운영 환경에서의 확인은 수행하지 않았다.

관련 기록은 [회원 관리 API 연결](2026-10-29-customer-management.md)에서 확인할 수 있다.
