# 2026-11-16 추천 질문에서 "지난 달 지점별 매출 비교" 제거

## 1. 배경 / 문제

- 사용자 요청으로 추천 질문 목록에서 "지난 달 지점별 매출 비교"를 뺀다.
- 이 항목은 2026-11-13에 "이번 달 지점별 매출 비교" 바로 옆에 추가했던 같은 분석(POC-001)의 기간 변형이었다.

## 2. 결정 및 이유

- 추천 목록은 등록 분석마다 하나씩 보여주는 원래 구조로 되돌렸다.
- 매출 비교 항목의 이름은 "이번 달 지점별 매출 비교"로 유지했다. 질문이 이번 달을 조회한다는 점이 이름에 드러나도록 하기 위해서다.
- 서버는 질문의 기간을 읽으므로, "지난 달 지점별 매출을 비교해줘"를 직접 입력하면 지난달 결과가 그대로 나온다. 백엔드는 바꾸지 않았다.

## 3. 구현 내용

- `domainlens.ts`의 `SUGGESTED_QUESTIONS`에서 지난달 항목을 없앴다.
- `Ai.test.tsx`: 지난달 항목을 확인하던 테스트 두 개를 지우고, 그 항목이 보이지 않는지 확인하는 테스트로 바꿨다.

## 4. 검증 결과

- `npm run typecheck`, `npm run lint` 통과.
- `npm test`, `npm run build` 통과.
- 실제 화면 확인은 하지 않았다.
