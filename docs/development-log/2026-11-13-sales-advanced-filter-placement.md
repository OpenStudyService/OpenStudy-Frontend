# 2026-11-13 · 매출 조회 고급 필터 배치 조정

## 1. 배경 / 문제

매출 조회 조건 카드에서 고급 필터가 기본 필터보다 먼저 나타나 화면을 읽는 순서가 어색했다.

## 2. 검토한 선택지

고급 필터를 기본 입력 행 바로 아래 또는 집계 지점까지 포함한 기본 조건 전체 아래에 배치하는 두 위치를 검토했다.

## 3. 결정 및 이유

기본 기간·환불 기준·결제 용도와 집계 지점을 먼저 보여 주고 고급 필터를 그 아래에 배치했다. 자주 사용하는 조건을 먼저 훑고 필요한 경우 고급 필터를 펼칠 수 있다.

## 4. 구현 내용

매출 조회 조건 카드 안에서 기존 `AdvancedFilters`를 집계 지점 다음으로 옮기고 기본 입력 행과 왼쪽 여백을 맞췄다.

## 5. 검증 결과

- 관련 Vitest 3개 파일·44개 시험, 타입 검사, 린트, live·MSW 빌드 통과.
- Chrome Playwright MSW 빌드에서 1440·1024·390px의 집계 지점 아래에 고급 필터가 표시되고 펼침·접기가 동작하는 것을 확인했다.
- `graphify update .`를 실행했다.

## 6. 남은 작업 / 보류 사항

- 이번 배치 조정은 관련 시험과 브라우저 시나리오를 검증했다. 전체 Vitest는 직전 커밋에서 771개가 통과했다.
