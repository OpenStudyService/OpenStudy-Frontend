# 2026-11-13 · 매출 조회 고급 필터 드롭다운

## 1. 배경 / 문제

고급 필터를 펼치면 조건 카드가 길어졌고, 상품 유형과 환불 처리 지점의 다중 선택 목록이 필터 영역을 차지했다.

## 2. 검토한 선택지

기본 선택 상자로 바꾸는 방법과, 펼쳐지는 체크박스 목록으로 여러 항목을 선택할 수 있게 하는 방법을 검토했다.

## 3. 결정 및 이유

고급 필터는 버튼 아래에 열리는 패널로 표시하고, 상품 유형과 환불 처리 지점은 체크박스 드롭다운으로 표시한다. 여러 조건을 함께 쓰는 기존 조회를 지원하고, 닫힌 상자에서 선택 상태를 확인할 수 있다.

## 4. 구현 내용

- 매출 전용 Radix Popover를 사용한다. 이용권 사용량 탭의 상품 유형도 같은 선택 UI를 사용한다.
- URL 조건 읽기와 적용 조건 표시는 기존 공용 함수를 사용한다. 결제 화면의 고급 필터 구현은 이번 변경 범위에서 제외했다.

## 5. 검증 결과

- 관련 Vitest 44개, 전체 Vitest 87개 파일·771개, 타입 검사, 린트, live·MSW 빌드 통과.
- 계약 시험에서 상품 유형과 환불 처리 지점의 다중 선택 및 요청 값을 확인했다. Chrome MSW 데모의 390·1024·1440px에서 열기, 선택·해제, Esc 닫기와 초점 복귀를 확인했다.
- `graphify update .`를 실행했다.

## 6. 남은 작업 / 보류 사항

- 브라우저 검증은 Chrome MSW 데모에서 수행했다. 실제 API와 다른 브라우저는 미검증이다.
