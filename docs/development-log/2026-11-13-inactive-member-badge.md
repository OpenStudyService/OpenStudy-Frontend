# 2026-11-13 비활성 회원 배지 색상

## 배경 및 결정

공용 배지는 상태 문구에서 색상을 추론한다. `비활성`에 포함된 `활성`이 먼저 일치해 정상 회원과 같은 녹색으로 표시됐다. 회원 상태 배지에 기존 노란색 계열을 명시적으로 적용하고, 공용 배지의 기본 색상 추론은 유지했다.

## 구현 및 검증

- 회원 목록, 상세, 편집 충돌 시 최신 회원 비교에 동일한 상태 배지를 사용한다.
- 회원 목록과 상세에서 비활성에 노란색 스타일이 적용되는지 확인했다. 전체 Vitest 807건, 린트, 타입 검사와 운영용 빌드가 통과했다.
