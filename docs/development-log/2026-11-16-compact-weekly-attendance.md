# 2026-11-16 주간 근무표의 출퇴근·휴게 기록 그룹

## 배경과 결정

시간 길이에 비례한 근무 막대는 여러 직원의 시간이 겹칠수록 날짜 열과 화면을 크게 만들었다. 날짜 열마다 출근·퇴근·휴게 시작·휴게 끝을 시각과 이름으로 표시하도록 바꿨다. 한국 시간 기준 날짜와 표시 분, 동작이 같은 기록을 한 줄에 묶어 직원별로 같은 시각을 반복하지 않는다.

## 구현

- 각 기록을 발생한 날짜의 열에 시각순으로 표시한다. 진행 중인 출퇴근·휴게에는 기록이 있는 동작만 표시한다.
- 예정 근무는 시작·종료 범위와 이름이 표시되는 짧은 항목으로 열 수 있다. 자정을 넘기는 예정 근무의 종료에는 ‘다음 날’을 붙인다.
- 전체 지점에서는 이름 옆에 지점도 표시한다. 조회 범위는 기존 주간 API가 반환한 기록을 따른다.
- 이미 병합된 PR #139의 작업 브랜치를 재사용하고 후속 PR에서 변경을 검토한다.

## 검증

- 타입 검사, ESLint, 전체 Vitest 859건, 운영용 빌드 및 빌드 검사 통과.
- Chrome 모의 API 테스트 3건 통과. 출근·휴게 시작·휴게 끝·퇴근 표시, 직원 조회 범위, 예정 근무 상세와 야간 시간 표시를 확인했다.
- 회귀 테스트에서 초가 다른 같은 분의 동작을 묶고, 자정을 넘긴 휴게 끝과 퇴근이 다음 날짜 열에 표시되는 것을 확인했다. `graphify update .`로 작업공간 그래프를 갱신했다.
- 운영 서버를 연결한 브라우저 검증은 수행하지 않았다.
