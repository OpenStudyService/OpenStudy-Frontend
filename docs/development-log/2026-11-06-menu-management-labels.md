# 2026-11-06 운영 메뉴명을 관리 중심 명칭으로 변경

## 배경 / 문제

사용자가 여섯 운영 메뉴를 회원 관리·상품 관리·결제 관리·공간 관리·시설 관리·근무 관리로 변경하도록 요청했다. 기존 일부 화면 제목은 메뉴명과 달라 함께 정리할 필요가 있었다.

## 결정 및 구현

최신 main `bba99c4`에서 `feature/menu-management-labels`를 생성했다. 사이드바·모바일 메뉴·상단 경로 표시의 공통 navigation 명칭과 각 화면의 제목을 맞췄다. 범용 화면 카탈로그의 명칭도 같은 기준으로 변경했다. 시설 등록·점검 동작의 기존 버튼명과 경로·권한·API는 유지한다.

기존 상품·결제·접근성 회귀의 메뉴/제목 선택자를 새 표시명에 맞췄다. 생성 API 타입의 주석과 과거 개발 기록은 당시 계약·기록이므로 바꾸지 않는다. 기존 미추적 `.gitattributes`는 포함하지 않는다.

## 검증 결과

- TypeScript와 변경 파일 ESLint 통과.
- Mock 운영 빌드·산출물 오염 검사 통과. 기존 500KB chunk 권고는 남는다.
- Chrome에서 여섯 메뉴의 링크 이동·화면 제목·상단 표시와 390px 모바일 메뉴 명칭을 확인했다.
- 기존 상품·결제·미저장 입력 보호 Chrome 회귀 7개 통과(17.7초).
- `graphify update .` 완료(2,757 nodes / 8,257 edges). 기존 SQL 추출 의존성 누락 경고는 남는다. 그래프는 로컬 출력이다.
- 운영 배포·실제 모바일 기기는 검증하지 않았다. 작업 브랜치 push와 PR 준비 후 사용자 병합을 기다리며 원격 main 변경·병합·자동 병합은 수행하지 않는다.
