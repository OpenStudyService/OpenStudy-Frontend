# v8 레이아웃 개정 안내

## 참고 자료

사용자 제공 `OpenStudy_DomainLens_Demo_v8_Layout_Refined.html`을 시각·상호작용 참고 자료로 사용했다. 원본은 수정하지 않았으며 참고 파일 SHA-256은 개발 기록에 남긴다.

## 달라진 화면

- 남색 내비게이션, 옅은 청회색 배경, 넓은 흰 대화 영역과 청록색 강조색.
- 하단 대표 질문 6개, 전체 36개 예문, 별도 상태·예외 질문.
- 가로 너비 슬라이더, 추천 영역 드래그/방향키 조절, 추천 숨기기·보기, 입력창 높이 조절.
- 질문 전송 시 추천 영역을 접어 결과에 공간을 제공하고, 대화창 내부에서만 스크롤한다.
- 실행 추적 패널에서 현재 사용자·채널의 요청 상태와 QuerySpec/ViewSpec 협의용 초안을 확인한다.
- 공유 기록은 사용자가 공유한 메모리 스냅샷만 보여 준다. 대화 원본을 AI가 자동으로 재구성하거나 서버에 저장하지 않는다.
- DB 도메인 메뉴는 실제 근거 테이블·필드와 API 준비 상태를 설명한다.

기존 34개 예문에 요일·시간대별 좌석 이용 시작 건수와 이용권 TOP 5를 더해 36개로 확장했다. 히트맵은 동시 점유율·예측이 아닌 입실 시작 건수이며, 좌석 배치는 지점별 상태 합계에 맞춘 가상 배치다. 스터디룸 예약은 주간 캘린더와 원본 표를 함께 보여 준다.

## 실행 방법

가장 간단한 방법은 같은 폴더의 `OpenStudy_DomainLenz_Demo.html`을 여는 것이다. ZIP을 풀어 어디로 이동해도 worktree·Node·서버와 독립적으로 동작한다.

소스가 있는 저장소에서는 다음 명령을 사용한다.

```sh
npm ci
npm run dev:domainlenz
```

전용 미리보기 주소는 `http://127.0.0.1:5195`다. 일반 프로젝트의 `npm run dev`는 mock 앱, `npm run dev:live`는 실제 API 앱이다. 프로젝트 채팅은 기존 앱 디자인을 유지하고, 새 추천 질문과 동적 결과를 같은 렌더러로 제공한다.

## 시연 순서

1. 대표 질문 카드 선택 → 질문 입력 확인 → 보내기.
2. 결과 조건·KPI·표와 히트맵·좌석 배치·캘린더를 확인.
3. Trace 또는 개발자 보기로 조회 근거 확인.
4. 채널에 공유 → 왼쪽 공유 기록에서 스냅샷 확인.
5. 추천 질문을 다시 열어 분할 높이·입력창 크기 조절.
6. 워크플로 버튼으로 매출 → 히트맵 → 판매 순위를 순서대로 시연. 중지하면 이후 자동 질문은 실행하지 않으며 진행 중인 개별 조회는 대화창의 조회 취소로 중단할 수 있다.
7. 사용자·채널 변경으로 권한 제한과 개인 기록 초기화 확인.

첨부 파일의 승인함·CSV 생성·자동 업무 기록은 이번 조회 시연에 추가하지 않았다. 실제 엔진·DB·서버 권한·성능 측정도 후속 범위다. 기준 시각은 기존 데이터와의 일관성을 위해 2026-10-17 11:00 Asia/Seoul을 유지했다.
